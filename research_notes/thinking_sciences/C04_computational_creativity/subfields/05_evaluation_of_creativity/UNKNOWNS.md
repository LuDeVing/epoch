## Open questions we cannot test on our bench yet

- **Execution of ideas by humans.** The only outcome study used 43 experts for 100+ hours. We can only use automatic checks. Unblock: build a small set of open ideas whose value can be run (code tasks, puzzle generators) and treat their pass rate as the outcome.
- **Expert-rated idea set.** All judge tests need 40-60 ideas with at least 3 trained raters and a reliability number. We have none. Unblock: rate our own agent's ideas by CAT (independent, pooled), report split-half first (human baseline 56.1%).
- **Later-uptake outcomes (HindSight style).** Needs a time-split and a large paper pool. Unblock: a fixed-cutoff corpus (the literature-grounded and HindSight papers give recipes).
- **Surprise as a separate axis.** Judged worst in the only test (tau -.01); no code-run surprise measure found. Unblock: define surprise as low probability under the agent's own earlier-ideas model and test against rated surprise.
- **Re-reading abstract-level numbers.** RQ-Bench win rates, RINoBench F1 17.2, Bhushan rho .732 and Tutone tau values were not re-opened in full text. Unblock: one reading pass before any threshold is set from them.
- **Newest-model drift.** Most judge numbers are 2023-2025 models, plus a few 2026 ones with small samples. Unblock: rerun B2 each time the base model changes.
- **Domains outside NLP and AI research ideas.** Nothing here covers ARC-style or puzzle ideas. Unblock: our own rated set per task class.

## Order to run

1. **U1 (execution vs judge pick):** it tests the biggest claim (G8 and the whole open-mode selector) cheaply on items that already have a check, and it decides whether any judge is worth building.
2. **U4 (k=3 pooling vs one long judgment):** cheapest change to any judge we keep, and the k curve is missing from the literature.
3. **U2 with U3 (retrieval plus claim attribution):** the only judge design with some support from several papers; run on one rated set to see whether grounding lifts agreement and cuts false "novel".
