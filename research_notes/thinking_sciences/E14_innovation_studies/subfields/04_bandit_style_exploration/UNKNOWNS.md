## Open questions we cannot test on our bench yet
- Whether a 2025-2026 frontier model still shows suffix failure on a standard bandit. Needs a bandit stub (5 arms, gap 0.2, T=200, N=40 as in Krishnamurthy) wired to our model; cheap once built, but it is a probe, not a schema test.
- Whether the knowing-doing gap persists with thinking mode. Needs the same stub plus rationale checks against true UCB values.
- Neutral replication of RND/ICM outside Atari. Needs outside labs. No action for us.
- Whether Thompson or UCB is better with only a few passes per class. Needs more logged history than we have; U2 replay will show how much data we lack.
- Class-dependent exploration weight at scale (U12). Needs enough items per class for power.
- Learning-progress rewards need several scores per task [d15]. Our per-class data may be too thin. Unblocked by more logged runs.
- Equal-token cost of a node-picking call in archive-and-return. Needs our own token accounting per call.
- Verification of 2026 preprints (d06, d07, d08): model names and replication. Unblocked by reading the final versions.

## Order to run
1. **U2 (offline replay).** Costs no model calls; picks the window, gamma and prior that U1 and U4 need.
2. **U3 (try-all-once) and U4 (code UCB vs model-chosen widen).** Cheap, both only change S6 control, and both reuse the code-computed class table (A2).
3. **U1 (per-class Thompson vs fixed width vs progressive widening).** The main open question in this subfield; run it with settings from U2 once U3 and U4 show the code table works.
