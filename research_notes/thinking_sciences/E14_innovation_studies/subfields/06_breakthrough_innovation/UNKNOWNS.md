## Open questions we cannot test on our bench yet

- Real-world value of LLM ideas outside ML: needs wet-lab, materials or other execution or an expert panel; our bench has only runnable code and puzzle checks.
- Citation-style impact labels (breakthrough = top 5% cited) for generated ideas: there is no citation outcome for an agent's idea. Unblock with a held-out later-label design on real papers.
- Replication of Kaplan and Vakili on non-patent data: needs a paper or code corpus with a topic-origination method; a separate scientometrics project.
- Which disruption-index variant is robust: not needed for the schema; do not use it as a label. A neutral adjudication would be needed.
- Reasoning-model and 2026-model behaviour on idea diversity at equal tokens: needs a run on the models we use; part of U1 and U7.
- Team effect (37.7% more atypical combinations) in a single agent: only a sampled-persona merge is testable, and only for diversity (U8), not value.
- Whether the generating model can be allowed to select among a pool filtered by code: G8 forbids it; testing this needs an exception, so only run it as a measurement, not as a design.
- Hits and heavy tails need large samples; our bench sizes (20 to 40 items) give weak power for rare wins. Unblock by logging every candidate and reusing runs across tests.

## Order to run

1. **E14.06-U3** (execution-ranked vs self-score vs tournament): it tests the single largest risk, that selection by opinion is near chance, and it needs only tasks that already have checks.
2. **E14.06-U1** (plan-then-split diversity): cheap, uses existing NoveltyBench items, and a pool that is not saturated is a precondition for any selector to work.
3. **E14.06-U4** (diversity reserve): small extra cost, and it tests whether the tail wins that drive the whole field's outcome are recoverable; run it on the same items as U3.
