## Open questions we cannot test on our bench yet

- Independent replication of RBF-HS and DynamicHS. Need a second group's code and non-ontology benchmarks (circuits, software, configuration). Four citers are indexed; open them to see if any re-ran the algorithms (d14, d15).
- Token or call counts for QXR. The paper reports none. Unblock: run U1 ourselves or ask the authors.
- Calibrated LLM fault priors for realistic diagnosis tasks. Need labelled fault cases with known truth and a calibration metric; current evidence is about answer confidence only.
- Diagnosis literature from 2023 to 2026 that uses LLMs. The API search could not run (rate limits). Unblock: repeat the Semantic Scholar and OpenAlex queries later.
- Human side: users ignored a stop instruction even when the true fault was ranked high (c18, c19). A matching test for an LLM that over-verifies after a pass needs a bench item with a known first-pass answer.
- Scale where exact enumeration matters (hundreds of suspects, many independent faults). Our bench has few such items. Unblock: build a synthetic bench with 100-500 components.

## Order to run

1. **U1 (QXR at equal tokens).** The only LLM-tested idea here, large reported effect, cheap to build; the equal-token check is the missing piece.
2. **U3 (bisection on reasoning chains).** Closest to our bench items and informs error localisation in S7; indirect evidence suggests a real gap to close.
3. **U4 (carry the suspect set forward).** Cheap to build and tests the memory idea behind DynamicHS under a real window limit; U5 can reuse the same items.
