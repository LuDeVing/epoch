## Open questions we cannot test on our bench yet
- What the 1968 Wallace and Boulton paper reports (data, class counts, 10-bit thresholds). Unblock: obtain the full text through a library or the Monash reprint.
- Independent MML versus AIC/BIC replication. Unblock: a full literature pass once API rate limits clear, or a small statistics toy we run ourselves.
- Whether MML and MDL disagree in practice outside logic programs, with numbers. Unblock: a second head-to-head study, or our own toy on mixtures.
- Whether any 2020-2026 LLM paper uses MML under another name (MML87, MMLD, two-part code). Unblock: full-text search across arXiv, not listings only.
- Limits of compressing agent memory before reuse fails (Lester-style learnability). Unblock: a memory-compression sweep on our own lesson library.
- Whether the MML advantage in d01 comes from the prior term. Unblock: an ablation, which the authors did not run.
- A frontier-model code-length selector needs token log-probabilities. Unblock: an API or model that returns them.

## Order to run
1. U1 (code-length rank versus majority vote): cheapest, uses existing sampled candidates, answers the biggest gap in the literature.
2. U3 (prequential versus two-part trace scoring): offline on stored traces, no new generation, and a null result also tells us whether trace-level scoring is worth pursuing.
3. U2 (shortest-rule tie-break on ARC): a single added line in S7 on items we already run, so cost is near zero.
