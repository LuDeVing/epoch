## Open questions we cannot test on our bench yet
- Independent replication of MADIL. Needs the OCaml repo run on the public sets. The MADIL citer list was not retrieved (rate limits). Unblocks: build the repo and rerun 100 tasks.
- Flat or learned prior for MADIL's code lengths (tests the idea against the hand DSL). Needs changes to the OCaml code.
- False-positive rate as a function of number of examples and rule length. Needs many samples per task and many tasks. Needs a large sample budget beyond our bench.
- Human versus model description length (H-ARC descriptions never analysed for length). Needs the H-ARC data and a coder for the text.
- Team write-ups from ARC Prize 2025 (selection methods). Not opened. Unblocks: read the top five.
- Private-set behaviour of the 2026 refinement systems. Needs the ARC Prize evaluation service.
- A true bits-based code length for LLM programs (a universal code or a model-based code). No agreed measure; the AST count in U1 is a proxy.
- Whether the effect holds off grid puzzles. No coding scheme exists for word problems.

## Order to run
1. **U2 (oracle gap audit).** Costs only logging. Tells us whether U1 and U10 are worth running at all.
2. **U3 (guard ablation).** Cheap, code-only, and tests the best-supported failure (fit-but-wrong, four sources).
3. **U1 (shortest vs vote on the contested subset).** The decision-relevant test nobody has run. Run it only if U2 shows a gap of 5 points or more.
