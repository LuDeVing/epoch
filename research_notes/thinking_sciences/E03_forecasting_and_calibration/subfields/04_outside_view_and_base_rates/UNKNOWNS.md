## Open questions we cannot test on our bench yet
- **Lovallo and Kahneman 2003 and Lovallo, Clarke and Camerer 2012 numbers.** Neither was opened. Needs full text to read N, design and effect. Needed to anchor the order rule and the "many analogies" claim.
- **Randomized human test of the outside-view instruction alone.** None exists. Chang's tag result is correlational. Needs a new human study; not on our bench.
- **Real-project test that reference class forecasting improves outcomes.** Needs field data. Our bench has only forecasting questions and our own run logs.
- **Raw unit of the Chang standardized score.** All means are positive; the transform is not stated. Needs the authors' data or code.
- **Strong-model behaviour with S0 hidden inside the model.** Frontier reasoning models may already use a class unprompted. We see only output transcripts. Needs access to reasoning traces.
- **Question sets with enough power.** 100 questions cannot see 0.01 Brier. We need 300+ resolved questions with known class rates, resolved after the model cutoff. A live or pastcast set (ForecastBench-style) would unblock this.
- **Classes for non-forecasting tasks (ARC-style puzzles).** No countable class of past puzzles with outcomes is known to us. A labelled log of our own solved and unsolved tasks would unblock this.
- **Politics vs psychology of optimism (K05).** Not testable on a single agent. It matters only if users press for rosy answers.

## Order to run
1. **U1 with U3 inside it (first vs late vs none, plus a class-free number arm).** It is the core question for the S0 gate and no study answers it. U3 stops us crediting an anchor effect to the class.
2. **U2 (computed vs retrieved vs recalled class).** Direction is already clear, so it is cheap to confirm, and it decides how S0 gets its number.
3. **U4 (band around extreme class rates).** The largest measured loss in the literature (0.04 Brier at extremes) and a code-only fix, so it is cheap to run on the same items as U1.
