## Open questions we cannot test on our bench yet

- Whether most LLM errors are illogical rather than human-like (A01.09-K26, one paper, older models). Needs a hand-labelled sample of about 100 failures from our own runs.
- Whether hypothesis-search gains hold on tasks with no oracle or answer key. Needs an open-ended induction set with a human-graded key.
- Belief updating across many turns (A01.09-K28). Needs a multi-turn evidence set. Tuning is out of scope; only the memory design matters.
- Whether a "use natural frequencies" instruction is actually followed (A01.09-K05, about 1.5 sources). Needs trace logging of compliance. U1 can log it.
- Whether success on famous items is memory or pattern matching (A01.09-K09). Needs unseen item sets. Build them with the mutation tool from U7.
- The real human baseline on the ARC test set (the 85% figure is from the train set). Needs published test-set human data. It does not change the schema, so skip it.

## Order to run

1. U1 (extract then compute for base rates): high gain, cheap, no source tests it, and it shows whether code arithmetic alone carries the benefit.
2. U4 (selector comparison for hypothesis search): the main published loss is selection, and it reuses our ARC portfolio and logging.
3. U5 (do search gains survive on current models): cheap once U4 runs, and it decides whether hypothesis search stays in the schema.
