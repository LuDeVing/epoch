## Open questions we cannot test on our bench yet

- Step starvation: whether old open items are ever dropped in an LLM agent. Needs a trace logger that records the age of each open item and which one was expanded. Unblock: add the log field in the harness first, then U1 can report it.
- Step-level subsumption for natural-language steps. Needs an exact or near-exact equivalence test between two reasoning steps. Unblock: restrict to items with formal or code steps, where equivalence is checkable.
- Newer frontier models on translation-vs-solving. Only GPT-3.5, GPT-4, GPT-4o era numbers exist. Unblock: run U5 on current models; no new literature is needed.
- LLM clause selection inside a real prover (U13). Needs a local E or Vampire build, a Mizar-style problem set and a way to call an LLM with a tight time budget. Not a bench item.
- Whether Haken-style proof-size limits relate to any LLM benchmark difficulty. Haken was not opened. Unblock: read the source and the proof-complexity survey, then check for a link to ProverQA depth.
- Peer-reviewed confirmation of the 2026 Vampire preprint numbers (a22, a23). Unblock: replication or a later venue version.
- Unread: Bostrom et al. 2022, search over statement compositions with a learned scorer, nearest LLM given-clause design. Unblock: open the PDF and extract results.
- Original papers not opened: Robinson 1965, McCune 1997, Bachmair-Ganzinger 1994. Not decision-relevant now.

## Order to run

1. **C06.01-U1 (age:weight step queue).** Largest expected gain, cheap to build (one counter in the selection code), and the only direct test of the central idea of this subfield; indirect support is already strong (d05: 11% vs 47%).
2. **C06.01-U4 with C06.01-U5 (solver routing plus translation audit).** Two kinds of data already exist (depth gain, PrOntoQA loss), so a probe plus a faithfulness check settles whether to add a solver path at all, using the same items.
3. **C06.01-U3 (refutation mode).** One extra prompt branch; the prover-side logic is clean and the depth-5 gap in d02 (94.2 vs 78.7) is the largest effect in the folder for deep deduction.
