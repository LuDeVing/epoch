## Open questions we cannot test on our bench yet

- **Live environments with irreversible actions** (web shops, file systems). We have no such task. Unblock by adding a small sandbox with a reset and a destructive-action tag (U11).
- **HotPotQA-style oracle ablation.** LATS's own gain without the ground-truth signal is unknown. Unblock by running the public LATS code with the oracle removed on 300+ questions; this is a reproduction, not a schema test.
- **Independent replication of LATS on HotPotQA and WebShop.** None exists. Unblock by running the public code once; compare to 0.63 and 75.9.
- **Cross-model stability of the 90% judge threshold.** Needs several models and tasks with known truth.
- **Trained value or reward models.** Large gains in the literature, excluded by the no-training rule. Unblock only if the project drops that rule.
- **Frontier reasoning models inside a tree.** Needs API budget to run the same tree on current thinking models at several thinking budgets (U8).

## Order to run

1. **U1 (tree vs retry vs best-of-N at equal tokens).** Decides whether S6 should be a tree at all; every other tree test is moot if retry wins.
2. **U8 (thinking-mode baseline vs tree).** Cheap, already first in SCHEMA section 7, and says whether the tree is redundant on current models.
3. **U5 (calibration gate for the tree) together with U4 (branch-majority readout).** Both protect the no-check route, where the evidence says a self-judged tree can hurt, and both reuse the U1 runs.
