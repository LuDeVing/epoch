## Open questions we cannot test on our bench yet

- **Text problems with no executable instances.** Scorer-writing and property checks need something to run. Missing: a set of item classes with code-checkable constraints, plus a small harness that runs a model-written scorer on tiny instances. Unblock: build 3 classes (schedule, grid, arithmetic) with generators and a smoke-test runner.
- **A property for free-text scorers.** Property-guided synthesis needs a check code can run (d06). We have none for open reasoning. Unblock: define one candidate property per class, for example "never ranks a known-failing child above a known-passing one" on a held-out log.
- **Real dead-end items.** We have no labelled set of "Mystery-like" text tasks. Unblock: write 30 items with use-once resources and one-way commitments, label by construction.
- **Equal-token accounting for the CPU part of selection.** In planning the cost is 206.25 CPU-hours per domain, not tokens (d06, d13). In text the model is also the evaluator. Unblock: log tokens for write, smoke, repair, selection and relaxed solve in separate columns.
- **Replication of the 2026 preprints.** LeanPlan, HTN, Gestrin and Seipp, property-guided synthesis and the routing paper were each read once; the table of LeanPlan was scrambled. Unblock: wait for replication or re-read with the paper tables.
- **Formal guarantees in free text.** LeanPlan needs a formal domain (d01). No counterpart for text. Unblock: none foreseen; restrict to executable classes.
- **LM-Landmarks full paper.** Only the listing abstract was read (d15). Unblock: find the PDF or contact route; until then treat as unverified.
- **Unopened classics.** Pearl 1984, Culberson and Schaeffer 1998, Bonet and Geffner 2001, Hoffmann et al. 2004 were not read. Low value for the schema, but their numbers are not in this document.
- **Forward citations.** Semantic Scholar and OpenAlex were rate limited, so work that cites Correa et al. may be missing. Unblock: rerun the search when quota returns.
- **Models beyond R1, o3, Qwen 2.5-72B, Gemini Flash.** Renaming and new-domain evidence rests on few models. Unblock: run E9 on every model we use.

## Order to run

1. **C05.02-U1 (relaxed rank vs real result).** The central open question. No paper answers it, and every other relaxation item depends on its calibration log.
2. **C05.02-U3 (must-pass list for the dropped constraint).** Cheapest. It tests the best-documented failure (dead ends) and costs one extra field per relaxed score.
3. **C05.02-U4 (scorer in code vs model rating).** The strongest measured pattern in the literature (373 vs 174), and the one most likely to turn into a real gain on executable classes if equal-token charging holds.
