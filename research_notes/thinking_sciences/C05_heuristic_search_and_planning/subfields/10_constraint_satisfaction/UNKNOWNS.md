## Open questions we cannot test on our bench yet
- **Independent replication of GenCP-style propagation during decoding.** Needs token-level model access and a CP solver around decoding. Unblock: an open-weights model with a hook, or an independent published replication.
- **Dechter width or tree decomposition for natural-language constraint lists.** Not searched and Dechter's book never opened. Unblock: read the book chapters on width and ordering, then test an ordering rule from U11.
- **Equal-token comparison against reasoning models.** Public numbers mix reasoning and chat models with unmatched budgets. Unblock: run both on our own models with the same token cap.
- **Diffusion language models propagating certain cells first.** Only a search snippet (c27). Unblock: read the paper and check whether it applies to hosted models.
- **RL-trained puzzle skills (Reasoning Gym, LogicPuzzleRL).** Training is out of scope. Unblock: only if the project ever allows training.
- **Cheeseman 1991, Mitchell 1992 and Freuder 1982 originals.** Read second-hand. Unblock: open the original papers before citing numbers from them.
- **Xu and Li Model RB threshold.** Abstract only. Unblock: open the PDF before using it to build hard test items.
- **Conflict-count threshold for tool use.** Partly covered by U4; needs our own per-size accuracy curves.

## Order to run
1. **U1 (propagate-then-guess at equal tokens).** The largest possible gain, and the only gap with no measurement at all. It also decides whether U6 and U7 are worth running.
2. **U2 (checker without solver).** Cheap: checkers are plain code. It tells us how much of the verifier gain is real and not extra tries, which sets the value of every checking step.
3. **U3 (back-translation of constraints).** Translation is the dominant error once code does the search, so this decides whether the solver route is safe to use.
