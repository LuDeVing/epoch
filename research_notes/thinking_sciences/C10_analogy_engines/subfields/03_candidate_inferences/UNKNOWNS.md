## Open questions we cannot test on our bench yet
- Gick and Holyoak 1980 raw numbers, the published Alfieri et al. effect size, and the Lassaline and Spellman and Holyoak numbers. Needs full-text access to those papers. Would let us compare human and LLM projection rates.
- A labelled benchmark of carried steps (base, target, each projected step true/false). None exists; we must build one (U1 needs it). Unblock by hand-labelling 60-100 items.
- Whether an LLM can do the skolem repair at all. No public task; U9 would create one.
- A blind expert correctness check of analogy-guided solutions. Needs outside raters.
- Whether Thought Propagation and Yasunaga gains replicate on a current model. Needs the original prompts and code.
- Human vs LLM causal-chain preference on the same items (to see if the human selection rule predicts correct LLM steps).
- Whether brittleness is training-data similarity or counting. The public data fit both; only new unseen task families would separate them.

## Order to run
1. **U1 (test-before-adopt).** It is the core claim of O7 and has no LLM measurement. It also builds the labelled item set that U2, U3, U4 and U13 reuse.
2. **U3 (mapping check in code).** It tests whether the code side adds value over the model's own source choice, with a clean metric and cheap setup once U1 items exist.
3. **U2 (two sources vs one).** The strongest human effect (48% vs 19%) with zero LLM data; the same items as U1, so it adds little cost.
