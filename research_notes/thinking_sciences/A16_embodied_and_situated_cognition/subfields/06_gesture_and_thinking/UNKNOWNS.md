## Open questions we cannot test on our bench yet
- Gesture itself. Our agent is text only, so we cannot test gesture production. Unblock: a multimodal agent with a drawing tool and a no-draw arm (PainterBench has the tool but no ablation).
- Preregistered replication of gesture prevention on spatial problems. This is a human study; we cannot run it. Unblock: a lab study; until then treat K05 as contested.
- Finger counting and action-simulation tasks for LLMs. No benchmark exists. Unblock: build one from counting tasks with and without an enforced intermediate marker.
- Learning cost-shifting across runs. Needs a bench with repeated problems per class and persistent memory (S9).
- Raw group means from Goldin-Meadow 2001 and Chu and Kita 2011. Unblock: author data or figure extraction.
- Whether prompt-only construction of layouts matches the fine-tuned gains (Qwen3-30B StepGame +9.9, SpartQA +43.3, d15). Needs a training-free comparison.
- Whether latent or image state beats typed state in our setting. Our stack is text only.

## Order to run
1. U1 with U2 (typed grid vs silent CoT vs best-of-N text at one token cap), because every other candidate depends on whether the grid wins at equal tokens, and G7 forbids adding it otherwise.
2. U3 (code check of the externalised state), because VoT and ASCII results show the state is often wrong, so a cheap check may decide whether the grid is usable at all.
3. U4 with U5 (signal-triggered grid, stratified by state size), because the only established failures are arithmetic-reducible and long-horizon items, and a gate cuts cost.
