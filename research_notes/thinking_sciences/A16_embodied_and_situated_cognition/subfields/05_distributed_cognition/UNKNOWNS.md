## Open questions we cannot test on our bench yet

- **Hutchins' propagation prediction** (how a representational state changes as it passes through the system). No LLM study tests it. We would need a logged chain of artifacts with known injected changes at each hop. U2 is a partial step.
- **Sparrow location-memory effect** in humans. It needs human participants. Unblock only if the multiplayer or human-study track starts. For agents, a location-index memory is covered by U5.
- **Frontier reasoning models in debate and critique tests.** Published re-tests use 7B-70B, GPT-4o-mini, Claude-3.5-haiku. Needs our own runs at frontier cost (U10).
- **Automatic decomposability measure.** Kim et al. use author-judged decomposability and trace-based predictors. Unblock by finding a pre-run proxy (U6 gives labelled data).
- **Long-horizon cross-run memory.** MATM shows gains over 274 tasks. Whether lessons from one run help later runs on a different class is untested. Needs a long run log (SCHEMA section 6).
- **Cost of offloading to the human side** (cognitive debt, motivation). Evidence is small, preprint or self-report. Not testable without human subjects; low weight.
- **Exact Zhang and Norman numbers**, Hutchins' book, Wegner 1991, Sparrow 2011, Risko and Gilbert 2016 were never opened. A reading pass would close the human side but would not change the schema.
- **Interface effects outside code.** SWE-agent is code only. Needs a non-code tool task on our bench.

## Order to run

1. **U1 (step-location verifier).** Cheap, uses checks we already have, and a win changes the S5 format directly. Prior evidence is strong on the repair half (+18 to +44 points with true location).
2. **U3 (predict-then-check before tool calls).** Cheap to build from the class record, no training needed, and also cuts tokens. No LLM evidence exists, so the value of information is high.
3. **U2 (redundant form mismatch check).** The central Hutchins claim with no LLM test. Cheap with injected errors. A pass would add a new guard to S8; a fail closes the analogy.
