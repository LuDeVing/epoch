# Go-Explore and archives: what we don't know and should test
*Candidates for the schema that are not established. Nothing here goes into SCHEMA.md until its test passes. Source: DEEP.md, claims.jsonl, critique.md in this folder.*

All tests: arms at equal total tokens (root runs, selection, resume, filter and verification calls all counted), at least 25 items per set and 3 repeats per arm, log source-entry score, child count and result for every resume. "Checker set" = ARC-style items plus a math or code set, each with a code-run check.

## Open questions we cannot test on our bench yet

- **Frontier-model behaviour.** All archive gains with an LLM selector use 2024 to early 2025 models. Only one 2026 test exists (negative). Unblock: run U1 and U2 with the current strongest model before any other claim.
- **Tasks with no checker.** Population and refine gains need an exact evaluator (K25, K33). Without one, expect the gain to vanish. Unblock: a pseudo-check (consistency across independent attempts) tested on a set with known answers; it is only a hint (G4).
- **Real long-horizon tasks.** Our bench is short-horizon (ARC items, puzzles). The strongest archive results are on long text worlds and agent tasks. Unblock: a small multi-step planning set with an exact checker (TravelPlanner-like).
- **Derailment in language models.** Only one RL robot study, and text restore is exact, so the mechanism may not exist for us. Unblock: nothing; test only its consequence (U1).
- **Separating archive from extra samples.** No source isolates archive structure from simply spending more calls at equal tokens. U1 does this for our case; for the literature it stays open.
- **Cross-problem archives.** Whether solved partials from one problem help another in the same class (link to Library learning). Unblock: a class-level store tested after U1 passes.
- **Model-selector bias.** IGE's authors warn about the model's blind spots on what is "interesting" (b27). Unblock: U5 plus a check of whether model picks over-favor familiar entry types.
- **Cost of DGM-style whole-agent archives.** About 22,000 USD per run and no variance. Not within our budget; borrow only the parent rule.
- **Seeds and variance.** The only variance evidence is from red-teaming (0 to 16 findings across seeds). We need our own run-to-run spread before any difference under 5 points is read as real.

## Order to run

1. **U1 (archive vs sampling, best-of-N, retry at equal tokens).** It settles the one gap every source leaves open and the only direct test so far is negative. Everything else depends on its outcome.
2. **U7 (re-check failure share) with U1's logs.** It costs almost nothing extra, and tells us whether archived solutions are even valid, which G3 requires.
3. **U3 (state key).** The key was worth about 11x in the original and is untested for reasoning. It is the cheapest way to improve U1's arm if U1 is promising. If U1 is flat, run U10 (gate) instead.
