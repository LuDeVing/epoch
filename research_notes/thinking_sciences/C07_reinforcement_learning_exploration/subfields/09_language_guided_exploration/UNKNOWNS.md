## Open questions we cannot test on our bench yet
- **Independent replication of ELLM, OMNI or IGE with a current model.** We need their code and an environment (Crafter, Game of 24 simulators). Citing papers were not searched because the search budget ran out. A fresh citation search would unblock this.
- **Tokens per success for any archive method.** No paper reports it. We would have to implement IGE ourselves with token logging.
- **Reasoning-model behaviour inside an exploration loop.** The only data are one game (Little Alchemy 2) and one decoding paper. We need a long-chain item set with a switch counter.
- **Author-independent oracle for "interesting".** OMNI's oracle was written by its authors. We need a human-rated set of sub-goals (a small panel) to test whether the model filter matches an independent judge.
- **Probe feasibility rates on maths and code.** Needs hand labelling of proposals on a sample of items. Cheap but manual; the missing piece is a labelled set.
- **Frontier-model repeats of the bandit studies.** Krishnamurthy and Schmied used 2023-2024 models. A small bandit harness with a current model would show whether the greedy collapse still exists.
- **iLLM River-Monster baseline.** One table cell has no named method. The PMLR paper's code or tables would settle it.
- **Interaction of LLM and curiosity signals.** Quadros's 3-run result is contested. Needs many seeds.

## Order to run
1. **C07.09-U4 (paraphrase spread):** cheapest test, and every other test needs its spread to judge a gain.
2. **C07.09-U1 (proposals vs regeneration loop vs novelty tie-break):** the central gap; no evidence outside games; decides whether an S3 probe step exists at all.
3. **C07.09-U2 (tried/untried summary table):** the largest measured effect in the literature (67 points), cheap to implement, and untested on frontier models.
