## Open questions we cannot test on our bench yet
- Independent replication of Ko and Myers 2005. Needs human think-aloud data or newly coded video. Reason (1990), Gilmore, Vessey and Perkins and Martin were not opened. Unblock: open those papers, then search forward by citation.
- Whether current long-thinking models still lose from self-correction on code. Needs an equal-token run with such models (see U14). The only data (Tsui) uses injected errors.
- Whether SWE-bench-style gains hold on clean data. Needs a bug set created after the model cutoffs.
- Whether LLMs have an analog of skill slips (copy errors, dropped context). Needs a coded error sample (U1, U18) and a long-context task set.
- Multi-agent step-location results (Who&When, AgentRx, DoVer). Need coded logs from our own system before they can be applied; our bench is single-agent.
- Whether a single decisive error step exists. DoVer found several different interventions can each repair one run. Unblock: run several interventions per failed run on our bench.
- Whether the atoms-of-confusion list (7 of 14 hold in Java) predicts model misreading. Needs a snippet set with clean twins and expert human data.
- Whether human bias results (anchoring survives expertise, reversal rate halved) say anything about agents. Needs an agent run with matched cues and no human counterpart.
- The Kim 2026 signal comparison (message vs pass/fail, about 13 points) is abstract-only. Unblock: open the full paper before relying on it.
- The search quota ran out during the gap search, so absence results (no Whyline-for-LLM, no is-a-change-needed gate, no chain-coded agent failures) need one more search round.
