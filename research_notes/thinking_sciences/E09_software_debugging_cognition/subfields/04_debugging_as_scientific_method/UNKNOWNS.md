## Open questions we cannot test on our bench yet

- **Do humans following Zeller's protocol debug faster?** No controlled trial found (K23). Needs human participants; not our bench. Not needed for the agent.
- **Is the 5x odds ratio causal?** Needs a human experiment that assigns hypothesis writing. Our U5 only tests the LLM version.
- **The classic findings (Gould, Vessey, Gugerty and Olson, Katz and Anderson, Parnin and Orso).** Never opened; exact numbers unknown. Unblock: obtain full text and extract numbers. Does not block agent tests.
- **Independent replication of AutoSD.** Needs another group or a held-out benchmark that the authors did not build (ARHE is self-built).
- **Prediction error vs wrong hypothesis on repository bugs.** Needs a repository-scale bench with executable tests and trace logging. Partly covered by U2.
- **Calibration of DONE on 2025 to 2026 reasoning models.** Needs labelled patches; U6 gives a first answer.
- **Per-bug-type effects in DebugBench.** Only in a figure; unblock by re-running the benchmark.
- **debug-gym Llama row.** Table and prose disagree (2.4 to 4.0 vs "hurts"). Needs a rerun.
- **Whyline in an LLM agent.** Needs a trace and why-not query tool built first.

## Order to run

1. **U2 (log prediction accuracy), run inside U1 arm B.** It costs only logging and tells us whether predictions can be trusted at all; it decides whether U1 is worth reading as a verdict.
2. **U1 (prediction step at equal tokens).** It is the main question for this subfield and nobody has isolated it; C arm separates logging from use.
3. **U4 (forced probe) together with U3 (validity gate).** Strongest recent evidence (8% to 99% call rate; 60.2 to 73.1) and the cheapest to build; U3 reuses the same logs.
