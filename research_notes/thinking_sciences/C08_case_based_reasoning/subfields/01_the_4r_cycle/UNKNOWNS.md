## Open questions we cannot test on our bench yet

- **Memento versus Evo-Memory on transfer (K18).** The two define similarity differently. Unblock: one shared similarity measure computed for every test item against its nearest stored case, logged from the first run.
- **Whether results hold at the model strength we deploy.** The memory papers use 2023 to 2025 models and small test sets (AIME has 30 questions). Unblock: run U1 on at least two model sizes.
- **Open-mode items with no ground truth.** The retain gate has nothing to check against. Unblock: a proxy check (the novelty-by-running rule, G8) and a measure of its precision.
- **Anchoring and lower diversity from retrieved cases (Stocker NOMAD).** One author, post hoc. Unblock: a diversity metric on NoveltyBench with and without the library.
- **Why the no-CBR baseline rose across passes in Memento (78.65 to 84.47).** Unblock: repeat-pass control with memory off (add to U1).
- **CASCADE (arXiv 2605.06702)** and Agent KB's full text were not read. Unblock: read before citing.
- **Judge precision on modern models.** The only measured value (about 17%) is GPT-4 on graph colouring. Unblock: U8.
- **Learned retrieval (Memento parametric, a Q-function).** Needs training, outside our scaffold-only rule. Non-parametric was within about 0.6 point at pass 5.
- **Human-source results (Gentner, Catrambone, Kubricht)** give direction only. Unblock: U7 and U15 are the first agent tests.

## Order to run

1. **C08.01-U1 (library vs empty library at equal tokens, with the repeat-pass control).** Every other row only matters if the library pays for itself, and no source has run this test.
2. **C08.01-U6 and U4 together (per-case harm log and similarity floor).** One logging change gives both; harm is real but uncounted, and the floor is the cheapest control.
3. **C08.01-U5 (skip rule by class pass rate).** It uses the class record we already keep in S0, costs almost nothing, and can save tokens in the same runs as U1.
