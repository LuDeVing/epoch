## Open questions we cannot test on our bench yet

- Whether the memory effect holds on current frontier models. Nearly all measured results are on gpt-3.5, GPT-4, GPT-4o, Gemini-2.5 and Claude-3.5/3.7. We would need a re-run of one reference study (for example the Xiong add-all vs strict setup) on today's backbone.
- Long horizons. Nothing is measured beyond about 4k items or 5 passes with eviction. We would need a stream of several thousand items with ground-truth labels.
- Variance. Almost all published numbers are single runs. We need at least 3 seeds and a way to report noise for each test above; without it, 2-4 point effects cannot be separated from chance.
- Cross-domain retrieval keys on large benchmarks. The only error-key result is two small coding sets.
- Open-world memory poisoning (MINJA, AgentPoison). Our bank is private; a shared bank would need a threat model first. Related to the multiplayer idea in the project notes.
- ARC-style memory. No published study exists. We would need our own ARC slice with grouped structure to build both "seen" and "novel" bins.

## Order to run

1. C08.04-U3 (memory vs equal-token retries). It decides whether S9 is worth its tokens at all; everything else depends on it.
2. C08.04-U1 (field ablation). It is cheap, has no prior result, and sets the record format that every other test uses.
3. C08.04-U7 (gain vs task similarity). It tells us when to use S9 on puzzles, and feeds the gate used in U2, U5 and U6.
