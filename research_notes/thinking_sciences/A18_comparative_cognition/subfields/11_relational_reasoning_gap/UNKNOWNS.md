## Open questions we cannot test on our bench yet

- Do reasoning models of 2025-2026 pass counterfactual alphabets at all? We have no access-free number. Unblock: run the Lewis and Mitchell item set (public) on current models.
- What exactly is in Monk, Meyer and Ngo (2024) on RMTS? Only an abstract was reachable (HTTP 403). Unblock: full text or the authors' data.
- Is there an LLM analogue of human load (Smith 2019) that is more than "long context"? We have only loose analogues (irrelevant premises, d10). Unblock: a design with matched distractor similarity.
- Where in the network does the relation get lost or fail to be applied (d08, d05)? Needs internal access. Unblock: an open-weight backbone on our bench.
- Are the animal replications (crow, pigeon transfer) sound? No independent replication found. This does not change the schema, so we do not pursue it.
- Effect size of the species gap across studies was never computed. Not needed for the schema.
- Is the 27% unintended-rule rate in d01 stable across annotators and tasks? kappa 0.70, one benchmark, one lab. Unblock: a second coding pass on our own items.
- Do human baselines (Prolific 0.753 vs undergraduates) change the size of any gap we report? Unblock: use one fixed human baseline per test or none.

## Order to run

1. A18.11-U13 (leak check): one hour of work, protects every other relational test from a shortcut.
2. A18.11-U4 and A18.11-U5 together (twin drop per class, and the code executor on permuted alphabets): they tell us whether the established fragility hits our backbone and whether code alone closes it, before any new operator is added.
3. A18.11-U1 with A18.11-U2 (role-filler table and relation-first) on the same far-analogy item set: the first real equal-token test of the relational-bottleneck idea in text, which the literature does not have.
