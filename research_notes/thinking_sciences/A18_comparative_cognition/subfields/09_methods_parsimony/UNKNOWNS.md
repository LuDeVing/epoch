## Open questions we cannot test on our bench yet
- Do published LLM ToM passes shrink on preregistered re-runs by other groups? Needs an outside replication literature; the search failed this round. Unblock by re-running the search when quota returns.
- Original-source counts for Krupenye 2016 and Hare 2001. Needs paywalled full text.
- Whether the Strachan P=.040 for irony and hinting is a copy error. Needs the original tables or the authors' data.
- Whether the GSM1k drop is contamination or generalisation. Needs training data, which only the model owners hold.
- Power of the order test on closed chat models. Needs prompt log probabilities that the APIs do not return.
- Whether any LLM agent loop uses a simplicity rule as an operator. Absence found, but search coverage was poor; redo a systematic search.

## Order to run
1. A18.09-U3 (twin pass gap): cheapest, code-made twins, and it sets the baseline every other test needs.
2. A18.09-U2 (default minus counterfactual gap): cheap, and it tells us whether the scaffold earns its tokens against G7.
3. A18.09-U1 (rival-plus-probe vs plain CoT): the one genuinely new operator and the one with the nearest negative evidence, so it needs the keep-answer exit and equal-token arms first.
