## Open questions we cannot test on our bench yet

- **Human effect sizes for the classic transfer results.** Needs the Alfieri, Nokes-Malach and Schunn (2013) meta-analysis (d14) read in full. Unblock: obtain the paper and extract the case-comparison effect size.
- **Independent novelty of analogy-first ideas.** Needs expert raters or a retrieval index of the prior literature in a domain where we can run code. Unblock: pick one domain with executable checks (materials, algorithms) and build the index.
- **Reasoning-model behaviour on 2025-26 counterfactual analogy tasks.** Needs access to current reasoning models with thinking and tools on our bench. Unblock: run U3 once models are wired in.
- **Quality of model-written typed relation graphs.** No data on parse and error rates. Unblock: small pilot of 50 stories scored against hand-made graphs.
- **Transformational creativity.** No task family defined where the rule change is verifiable. Unblock: design synthetic spaces with a known rule change and a code checker.
- **Spencer and Weisberg null versus Holyoak and Koh.** Context change and delay effects in humans. Of low use for the agent; only worth reading if memory-delay effects matter for the lesson store.
- **Hesse, Nersessian, Boden, ACME primary texts.** Not opened. No claim depends on them. Unblock: read ACME to decide whether a multi-constraint score (structure, meaning, goal) beats the structure-only check in U13.
- **Contamination of benchmark items.** We cannot tell which published analogy items are in training data. Unblock: use only fresh, generated items in every test above.

## Order to run

1. **D01.08-U3 (code for counting on counterfactual analogy):** cheapest, uses existing generators, and settles whether a code step is mandatory before anything analogical is trusted.
2. **D01.08-U2 (cue the source versus unaided recall):** cheap and decides the basic O7 design; established for humans, never tested for agents at equal tokens.
3. **D01.08-U1 (two sources plus written rule versus best-of-N):** the compute-matched test the literature lacks; it decides whether O7 deserves its tokens at all (G7). Run U5 and U6 in the same batch if retrieval infrastructure exists.
