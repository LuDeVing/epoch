## Open questions we cannot test on our bench yet

- **Independent replication of Branchini (36.66% to 78.33%).** Needs a third human lab or the authors' data. We can only check whether an LLM version of "list properties" vs "list opposites" separates (part of U1).
- **Original Tweney (1980), Gorman (1984) and Ragni (2018) numbers.** Not opened. Needs the full papers. Does not block any test.
- **Frontier-model standing.** FalsifyBench lists no Claude or Gemini frontier model. Unblock: run its 100 games on our model (needs the benchmark release).
- **Severity of a single falsification step.** Only suite-level detection is measured in the literature (d10, d11). We build our own planted-flaw sets in U3.
- **Duhem-Quine blame in LLMs.** No published study. U4 is a new design.
- **Open-ended reasoning and math.** All LLM falsification evidence is 2-4-6 games, REFUTE or POPPER. We need item types with a checker outside those families.
- **Klayman and Ha broader-hypothesis case for LLMs.** No study. U6 covers it if we build both game types.
- **Reasoning mode vs incompatible testing (FalsifyBench vs Failing to Falsify).** Needs both designs on one model set; our bench can run it as part of U1 and U12.
- **Exact severity formula.** Mayo's severity was read at abstract level only; a formal measure for non-statistical claims does not exist.

## Order to run

1. **U3 (planted-flaw detection of S4, isolated writer).** Cheapest, answers how severe our checks are, and every other test needs the planted-flaw sets it builds.
2. **U1 (opposite-test turn vs plain vs best-of-N).** The central missing measurement (K26); uses existing rule-game items and a code-inserted turn.
3. **U2 (refuter blind vs sighted vs random).** Reuses U3's wrong candidates and tells us whether S4 should generate tests with the model or with code.
