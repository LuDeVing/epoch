## Open questions we cannot test on our bench yet
- Does compilation itself (rather than the rest of the architecture) produce the human fits? Needs an ACT-R ablation with compilation off; nobody has published one. We could run an ACT-R model ourselves; that is outside the bench.
- Does the Taatgen 2008 instruction-format effect replicate outside the lab? Needs a human study with fresh participants.
- Do human practice counts (100-150 experiences) map to a useful k for an LLM? Only our own U1 sweep can say.
- Zhu and Reid (Soar productions from LLM reasoning): not located; a search by author name would unblock it.
- PRIMs transfer numbers from the journal version of Taatgen 2013.
- Total token cost with the write step in published agent-memory papers; reports do not give it, so we must recompute from released code.
- Compilation across tasks (transfer to a related family, K07): needs a bench with explicit task families; ours has classes but not graded relatedness.

## Order to run
1. U2 (regression gate vs no gate at matched spend): cheapest, strongest prior (GRASP), and it decides whether any routine write is allowed.
2. U3 (store on/off by position, gated vs ungated): answers whether the store pays at all and whether it decays, before we tune anything.
3. U1 (promotion threshold k): the one test that is specific to ACT-R and that nobody has run; run it on the same stream as U3.
