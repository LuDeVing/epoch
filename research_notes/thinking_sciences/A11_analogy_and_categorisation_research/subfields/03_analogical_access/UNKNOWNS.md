# Analogical access (retrieval): what we don't know and should test
*Candidates for the schema that are not established. Nothing here goes into SCHEMA.md until its test passes. Source: DEEP.md, claims.jsonl, critique.md in this folder.*

All tests: same base model in every arm, equal total tokens (counting tagging, restating, lookup and mapping passes), paired items, flips right-to-wrong and wrong-to-right logged. "Memory" means a store of the agent's own solved, checked subgoals (written only after a G3 pass).

## Open questions we cannot test on our bench yet

- **No memory of solved subgoals exists yet.** Most tests need a store built from passed runs. Unblock: log every G3-passed subgoal with abstract form and tags from the first bench run (SCHEMA section 6), then run U1 to U5 on the resulting store.
- **No class labels fine enough for tags.** Tag vocabulary is not defined. Unblock: derive a first vocabulary from the ARC and BRAINTEASER item types, freeze it, and check drift with U10.
- **Primary sources of the human numbers.** Gick and Holyoak 1980, Holyoak and Koh 1987, Novick and Holyoak 1991, Catrambone and Holyoak 1989 and Alfieri 2013 were seen only in restatements or abstracts. The no-hint rate ranges 10 to 43% by experiment. Unblock: library access to the primary PDFs; none of this changes a design choice now.
- **Frontier models are untested in this literature.** All access studies use 2023 to 2025 models. Unblock: our own runs (U8, U9, U15) are the only source.
- **Equal-token accounting is absent in the literature.** Unblock: our logging; results from papers cannot be used as equal-token gains.
- **Generation versus lookup for far analogies.** Human field data are contested (K16). Unblock: U13, plus a control that compares free generation with cued lookup on the same targets.
- **Whether comparison helps spontaneous retrieval or only retrieval on request.** Human studies mostly ask for a recall. Unblock: run U6 with the lookup inside the loop and no explicit instruction to find a relation.
- **Value of never-retrieved memories.** Some stored cases are never surfaced, so their value is unknown (d20, abstract only). Unblock: keep a few random slots in the lookup during U1 to U2 to estimate it.

## Order to run

1. **A11.03-U3 (probe rewrite, offline Hit@1).** Cheapest: needs no solving, only a paraphrase set and a store. It also shows the size of the wording bias on our own store and gives the data for U1.
2. **A11.03-U4 (no-match gate and mapping check).** Protects against the best-documented harm (false transfer, about 5 points). Any later retrieval test is misleading without it.
3. **A11.03-U2 (impasse trigger vs always-on vs none).** Highest value for the schema: it decides whether lookup lives only at S6, which is the one placement that keeps G1 intact. Run U1 (tag key vs embedding) with the same store right after, as it reuses the same items.
