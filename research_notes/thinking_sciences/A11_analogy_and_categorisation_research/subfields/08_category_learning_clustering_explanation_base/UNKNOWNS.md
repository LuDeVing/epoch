## Open questions we cannot test on our bench yet
- Human data for explanation-based learning: Pazzani (1991) and Minton (1990) were never opened. Unblock: fetch both full texts and extract numbers.
- Original Anderson 1991 and Tenenbaum 1999 human numbers are not verified first-hand. Unblock: obtain the open copies.
- Which stage of propose-test-refine fails first with 2025-26 reasoning models (generation, pruning, application). Unblock: a per-stage logging run on a labelled set; Jin 2026 and Jhaveri 2026 were not read.
- Whether human-like priors (ERMI-style) help a scaffold at all. Unblock: a prompt-level proxy of ecological priors; today it needs a trained network.
- Whether the prototype-to-exemplar shift has any use for S7 re-fit rules. The mechanism is contested; no test is meaningful until it is settled.
- Rule-library growth cost (the EBL utility problem) for an LLM agent. Unblock: a long-horizon run with a growing library and per-rule utility logs.
- Qiu noise results are in figures with no exact numbers. Unblock: rerun or contact the authors.
- Rule fit across a long run (S7 in a long-horizon agent). No study tests it; our bench has no long-horizon item type.

## Order to run
1. **U4 (rule as code):** cheapest, and it fixes the application gap that every other rule test depends on.
2. **U3 (distinct concepts first):** one prompt change, a measured gain with older models, and it sets up the pool test.
3. **U1 (weighted pool, new rule on surprise):** the central question of this subfield; run it after U3 and U4 so the pool uses distinct, code-checked rules.
