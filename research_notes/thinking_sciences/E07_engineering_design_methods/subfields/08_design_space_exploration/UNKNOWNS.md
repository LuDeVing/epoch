## Open questions we cannot test on our bench yet

- **Human designers.** No open human DSE or set-based design study was read; publisher pages returned 403. Unblock: get full texts (Papalambros, Deb 2001 book, human trade-off studies) through a library route.
- **Many-objective limit.** Ishibuchi et al. 2008 and Deb 2001 not opened, so the "about four objectives" limit rests on a bibliographic note. Unblock: read both. U9 gives our own number.
- **Hardware DSE replication.** iDSE, Lumina, MicroEvo have no independent replication. We cannot run them (simulators, FPGA tools). Unblock: public code and an independent group, or a cheap simulator.
- **2025-26 TSP size table.** No OPRO-style n=20-50 table exists for current reasoning models. Unblock: run it ourselves (U4 is the cheap version).
- **Gideoni et al. 2025** (random baselines competitive with code evolution) was cited but not opened.
- **Quality indicator for text pools.** Whether HV or any set indicator tracks the quality of a pool of text candidates is unknown.
- **Judge studies on design choice.** Position bias, non-transitivity and panel correlation are measured on chat quality and NLI only. Unblock: U1 and U2 log order sensitivity directly.
- **Cost accounting.** The literature uses queries, seconds and designs. Equal-token comparisons exist nowhere. Our tests supply them.

## Order to run

1. **U3 (best-of-N control vs scaffold).** It is the cheapest and it gates everything else: if plain best-of-N with a code scorer matches the scaffold, the other structure is not worth testing.
2. **U1 and U2 together (S7 pick by code, LLM, or staged pairwise).** They share one item pool, answer the main open gap (no paper tests LLM trade-off selection among text candidates), and tell us whether S7 can stay code-only.
3. **U4 (size cliff with and without a code enumerator).** It sets the option count S7 may use per backbone and checks that code offload keeps the result flat.
