## Open questions we cannot test on our bench yet
- Extracting "facts the subgoal used": Soar reads this from rule traces. We have text. The perturbation method in U3 is a guess; nothing published validates it. Needs a probe of which input features change the result.
- Voyager's gate versus retry control: verification there also steers retry (d02). To separate them we need a harness mode with a gate but no retry steering.
- Assanie (2022) thesis: the 12-issue correctness taxonomy and 14 agents / 8 domains evaluation. Blocked downloads. Unblock: open the PDF from another network or ask the author. The Soar manual list (d04) is the stand-in.
- Evans et al. (2018) and any LLM learning-curve fit: unopened; no study fits a curve to library gains. Unblock: get the paper; fit our own gain-per-entry curves after U1.
- Tie and conflict impasses in LLM scaffolds: Soar's 1986 authors had not met conflict impasses. We need logs showing how often each type fires before we can test typing (U2).
- Reasoning-task evidence is thin (Dynamic Cheatsheet AIME sets of 30; LEGO-Prover one run). Unblock: a 100+ item reasoning slice with code checks.
- Independent replication of 2026 single-group preprints (anti-persistence, SkillOps, AgentDebugX, mechanism review). Unblock: re-implement on our bench; do not rely on them.
- Newell (1990) and Laird et al. (1987): unopened primary sources for universal subgoaling. Low value for the schema; read only if a claim from them is needed.
- Kadu and Krishnan (2026): only the event page was read. The gate-versus-fixed-schedule ablation could answer part of U2. Unblock: open the workshop paper.

## Order to run
1. **U1 (trigger versus gate):** the central question of this subfield, and the only one that decides whether S6 should write to a library at all. Every other row depends on the answer.
2. **U6 (re-check at reuse, wrong-reuse rate):** cheap, uses near-duplicate pairs, and tells us the false-reuse rate no paper has counted. Protects against the main risk (propagated errors).
3. **U9 (entries per state, 1/3/6):** cheapest to run, shares the stream from U1, and sets the retrieval cap before any library goes live.
