## Open questions we cannot test on our bench yet

- **Human detour data.** Thomas (1974), Greeno (1974), Jeffries et al. (1977), Simon and Reed (1976) and Newell and Simon (1972) are paywalled; only abstracts or secondary text were read. Unblock: library access or direct copies. Until then U5 is an LLM test of a hypothesis, not a replication of human behaviour.
- **Whether the model can find a long decomposition, not just run it.** MAKER and the Thought-of-Search route supply the algorithm or the transition code. We have no item set that separates strategy finding from execution without a hand-made solution. Unblock: build items with a known optimal decomposition and score the model's own plan against it.
- **Replication of MEDAKA.** One preprint, one synthetic domain, two ablated models, thinking off. Unblock: the code and LiquidWorld items, or our own port to a second domain (U1, U2).
- **Checker accuracy needed for subgoal checks to help.** No source gives a number. Unblock: sweep a synthetic checker with a set false-accept and false-reject rate over U6 items to find the break-even point.
- **Items with no goal state (open mode).** MEA needs something to compare against. We have no way to define differences for open questions or novelty items. Unblock: a goal proxy (constraint list, rubric checked by code) or leave MEA off in open mode.
- **Serial decomposability as a class tag.** Korf's boundary (subgoals solvable in order without undoing earlier ones) is only known from abstract notes. Unblock: open Korf (1985) and test whether a cheap pre-check can tag items.
- **Always-decompose versus as-needed with reasoning models.** All ADaPT models are 2023 models. Unblock: U4 on our current model.
- **Hanoi collapse cause.** The dispute (Shojaee, Lawsen, Khan, Su, Dellibarda Varela, MAKER) has no clean single test. Unblock: U9 at N up to 15 with the four-by-two arm grid.

## Order to run

1. **A02.02-U1** (thinking on and off, equal tokens against CoT pass@k plus verifier). It decides whether any explicit MEA scaffold stays in the schema, and it is the one result the literature cannot supply.
2. **A02.02-U3** (final all-goals check on multi-goal items). It is cheap code, the classical case is solid, and nobody has measured the LLM clobbering rate.
3. **A02.02-U6** (ledger-recomputed subgoal check against a model-judged check). It tests the strongest negative finding in this subfield on our own items and tells us whether progress signals can come from code instead of the model.

U2 follows U1 using the same items, because it only needs extra arms.
