## Open questions we cannot test on our bench yet

- Fine-tuning an LLM on n-back or span tasks, then testing matrix and ARC reasoning with an equal-compute control (gap 1; no study found). Needs weight training, which our agent does not do. Unblock: a small open model and a fine-tuning budget, only if the schema ever allows trained components.
- Why RL game training transfers to math but not to ARC (ViGaL, SPIRAL, Reasoning Gym: no ARC gain). Needs RL runs with format and pretraining controls.
- A large preregistered multi-site human trial after 2017 (a 2025 trial was mentioned in search output but not identified). Unblock: a targeted literature search with a reliable API.
- Whether the active-control moderator is real (Melby-Lervag Q(1)=6.09, p=.01 vs Soveri diff 0.03, p=.429). Needs an independent re-analysis with common inclusion rules. Does not change the schema.
- Human individual differences (who gains: low baseline, strategy users). Concerns people, not our agent.
- Mechanism for LLM WM failure at n-back (attention dispersal vs task misreading vs interference) on production models. Needs access to attention weights or log-probabilities.

## Order to run

1. A13.05-U1 (placebo scaffold arm). It governs how every other result is read, it is cheap, and it applies to the whole scaffold.
2. A13.05-U4 (scratchpad vs free CoT at equal tokens). The key open head-to-head for the memory and state design; no one has run it.
3. A13.05-U3 (visible note for hidden state). Cheap, high expected gain, and it targets a failure no human-style fix can address.
