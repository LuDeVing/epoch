## Open questions we cannot test on our bench yet

- **Per-task human vs model correlation on ARC-AGI-2.** Not published; model scores were 0.9-3.0% at release. Unblock: run our agent and record per-task pass rate on the public set; correlate with the human table when released or with H-ARC ids on ARC-AGI-1.
- **Embretson 1995, 1998, 2004 numbers** (variance, cross-validation, attrition). Paywalled; second-hand only. Unblock: library access or an author copy. Does not block testing, only the human baseline.
- **Carpenter's 57% in a larger sample.** One study of 12 students. Unblock: a new human sample, or the model analogue in U2.
- **Within-level replication of Razavi's feature gains.** None found. Unblock: run U3 on our own families.
- **Whether IRT or Glicko difficulty has been used for reasoning-budget allocation.** Not found under a limited search (web quota ran out). Unblock: a second search sweep.
- **Hidden-state signals (Zhu, Lugoloobi, Brown).** Need white-box access. Unblock: an open-weight run, only if we ever leave the API.
- **Staleness across model versions.** Needs two versions and logged runs; covered by U7 when a second model is available.
- **Net token savings of published gates are author-reported.** No independent replication. Unblock: our own U1.
- **Whether the "stronger means worse" pattern is a ceiling effect or something else.** Critique says ceiling; untested. Unblock: compare on items with spread in pass rate.
- **Whether the persona versus aggregation conflict (Acquaye vs Li) reconciles.** Unblock: U5 with varied prompts.

## Order to run

1. **A13.07-U2 (rule count vs agent pass rate on ARC).** Cheapest: needs only logged pass rates and a code-side counter. It tells us at once whether the Carpenter feature transfers to a model, which sets the whole S0 feature design.
2. **A13.07-U5 (probe size and prompt variety).** Cheap and sets k for every later test; k = 2 vs 5 decides whether the probe can pay for itself.
3. **A13.07-U1 (probe gate vs fixed depth at equal tokens).** The decisive test for S0 and G12. Run it after U2 and U5 so the features and k are already fixed. U12's free baselines ride along on all three.
