## Open questions we cannot test on our bench yet
- Eigenoptions or covering options on a noisy, learned problem-state graph. Missing: a way to build a trustworthy state graph from text attempts. Unblock: first pass U8 to see if any code-built graph helps at all.
- Problem size at which hierarchy starts to pay for LLM reasoning (Solway's cost model). Missing: items graded by size on one task family. Unblock: build a size ladder (3, 5, 8, 12 steps) on 2 families, run U1 on each rung.
- Whether the human pseudo-reward prediction error result replicates at larger N. Not a bench question; only matters if U13 passes.
- Negative transfer from stale subgoals in LLM agents beyond our own library. Needs a changed-task set; U5 builds a small one.
- Whether reasoning models or tool-using models fix CogEval's cluster-crossing failure (0/30 for GPT-4). Needs a graph-item set with known ground truth; U8 builds it.
- Whether the Solway bottleneck-first effect and Schapiro community effect appear in LLMs. Needs text-graph tasks with a choose-a-subgoal prompt; a small side study after U8.
- Whether covering options fail only because of the single-state initiation set (Machado's conjecture). RL-side question, no bench access.
- Frontier-model replication of ADaPT with matched tokens. Part of U1; the original used GPT-3.5.

## Order to run
1. **U1 with U2 (decompose-on-failure and difficulty gate).** Cheapest, uses existing items, and decides whether O3 should fire at all before we build any library; tests G11/G12 at the same time.
2. **U10 (library vs flat control with the same samples).** If a plain diverse-sampling arm matches the library, the whole subgoal-library slot is not worth building; the answer saves later work.
3. **U12 (subgoal-status verifier), then U4/U5.** Any library depends on a trustworthy "reached/valid" signal and on admission by check; test this before mining or lifecycle work.
