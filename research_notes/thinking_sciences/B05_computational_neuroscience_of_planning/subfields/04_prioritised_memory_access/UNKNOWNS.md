## Open questions we cannot test on our bench yet
- **Human replication of Liu 2021 (N=29, gain over need).** None found among 128 citing records; the Neuron 2026 iEEG study (N=34) is an extension known only from its abstract. Unblock: a replication report or open data; we cannot run MEG.
- **True gain x need in a language model.** Needs the policy effect of a revisit before doing it. Unblock: a cheap simulator, such as running the revisit on a held-out copy of the item (costly at equal tokens), or a validated proxy from U2.
- **Whether LLM self-rated importance can ever work.** Unblock: U2 with a larger proxy set.
- **Ordering vs filtering in P2Value, MemRL, CodeIt-style methods.** Needs the original authors' code or ablation (priority vs uniform at equal sample count).
- **Multi-step (non-myopic) replay value in theory.** No paper found. Unblock: a theory paper or our own U6 result.
- **Compounding error in imagined continuations with real feedback.** Search found only listings (Imagine-then-Plan, GILP). Unblock: open those papers; test T11 (start from verified state, capped depth).
- **Founding rodent papers not opened in full** (Foster and Wilson 2006, Gupta 2010, Jadhav 2012, Widloski 2022, journal Carey 2019). They do not block any test; they only limit how hard we lean on the biology.
- **Rat vs human mismatch.** Gillespie 2021, Carey 2019 and Tirole 2026 (preprint, 3 decoded rats) disagree with a plan-driven reading; an account that fixes this at the level of gain is not tested in LLMs.
- **Recall of 2024-2026 LLM memory papers.** Search was throttled (OpenAlex budget gone, arXiv API 429). Unblock: a later search pass.

## Order to run
1. **U2 (proxy validation).** Cheapest, and it gates U1: if no proxy beats recency in rank correlation with true benefit, the gain x need ranking has nothing to run on.
2. **U1 (gain x need vs recency vs random).** The main hypothesis of this subfield. No direct test exists, and a positive result is the largest expected gain for the memory part.
3. **U3 and U4 together (backward revisit; dependants-first on changed facts).** Same planted-error and changed-fact items, so one harness covers both; the evidence is strongest here (reverse replay in rats and humans; STALE 55.2% to 68.0%).
