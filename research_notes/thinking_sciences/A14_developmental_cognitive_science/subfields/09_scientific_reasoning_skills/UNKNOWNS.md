## Open questions we cannot test on our bench yet

- **Real numbers in Chen and Klahr (1999) and Klahr and Nigam (2004).** The 77% vs 23% mastery figure is unverified. Unblock: an open copy or library access to the PDFs. It matters for effect-size anchoring, not for the bench.
- **Do human findings on instruction timing carry to a stateless model?** We have no memory across runs except the lesson lines. Unblock: a multi-run harness with persisted lessons (schema section 5).
- **Hypothesis-evidence coordination (Kuhn).** Multi-week designs are not reproducible in one call. Unblock: a multi-session simulator with delayed feedback.
- **MicroDYN or VOTAT on LLMs.** No published item set found; arXiv search was rate-limited. Unblock: a re-search when quota returns, or building MicroDYN-like linear systems ourselves.
- **Independent replication of Jhaveri and FalsifyBench.** Both are single-lab 2026 preprints. Unblock: wait for citing work, or run our own held-out rule families (U2, U9).
- **Reasoning effort vs falsification.** Reasoning models falsify more (c02) but more reasoning worsened AND exploration (d13). Unblock: one factorial test, thinking budget x rule type, on a model with adjustable budget.
- **Schwichow g=0.61.** Second-hand. Unblock: read the 2016 meta-analysis itself.
- **Pretrained base model behaviour.** No study tests one. Unblock: access to a base model on our bench.

## Order to run

1. **A14.09-U1 (sparsity-aware test rule):** it decides the exact wording of S4's "one change per test" and tests the biggest conflict in this subfield; the item set is cheap to generate in code.
