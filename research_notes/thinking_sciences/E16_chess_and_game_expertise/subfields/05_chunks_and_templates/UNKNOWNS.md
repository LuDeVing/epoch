## Open questions we cannot test on our bench yet

- **Perceptual chunking and the 2 s gap.** Text agents have no eye or hand. We could log retrieval bursts, but no source says what such a chunk metric would predict. Unblock: a defined content-based chunk metric (shared relations), then see if it predicts reuse.
- **CHUMP-style hit rate.** No published numbers for the pattern-to-move table (K11). Unblock: read the CHUMP paper, or build the table on our own solved items (U5).
- **Long-run library growth.** A log-like gain with library size is a model prediction (CHREST). We have no large solved-case library yet. Unblock: a stream of 500+ solved items with checks.
- **Far transfer (chess to maths style).** No true far-domain test exists in any source. Unblock: a second problem family with a different surface and a shared structure.
- **Template-theory vs constraint attunement vs role views for LLMs.** Needs the full Linhares and Brum paper (abstract only) and an interpretable retrieval key. Unblock: open full text; run U6.
- **Search vs recognition share.** Original Chabris and Hearst paper not opened (K10). Unblock: open it; run U9.
- **Pleiss et al. replication.** One model, one prompt, no retrieval arm. Unblock: run U8 with our models on our unfamiliar split.
- **Admission without ground truth.** Strict ground-truth checks gave the best results, but many of our items have no check. Unblock: test held-out agreement or mutated-input checks as the gate (links to G3).
- **Interference between templates.** Full-skill injection falls at larger k (SRA-Bench), but the cause (interference vs token cost) is not separated. Unblock: U4 with matched tokens and progressive disclosure (names first, bodies on request).
- **Human-expert training effects.** Trained-master result (N = 1, an author) cannot be tested on a training-free agent.

## Order to run

1. **E16.05-U3 (paired memory on/off on the same problems).** Cheapest, needs only the existing bench plus a retrieval log; it tells us whether any memory gain is real before we spend on formats.
2. **E16.05-U2 (top-3 hit rate and oracle gap).** Needs a small offline-labelled set; it splits cueing from extra reasoning, the main gap in the literature, and gates every other memory test.
3. **E16.05-U1 (core-plus-slots vs flat example vs snippet).** The central template-theory claim; run it only after U2 shows the retrieval is good enough, otherwise the format comparison measures retrieval noise.
