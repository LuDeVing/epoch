## Open questions we cannot test on our bench yet
- Is the chunk count constant, humped or flat for an LLM? We have no instrument for counting "chunks" in model output; unblock by fixing a unit definition and logging items per retrieved unit (DEEP.md 7, item 1).
- Do the human time constants (8 s, 2 s, 250 ms) have an LLM analogue? We cannot time a model's learning; at best compare token cost of writing a new note vs filling a slot.
- Store size needed by an agent library: no measured value even for humans (2,500 to 300,000). Needs a long run with a growing library.
- Does the Karvonen random-start collapse transfer to non-chess tasks? Needs a task family with a natural out-of-distribution start.
- Do independent labs replicate templates? Only Gong 2015 (mixed), Lane and Chang 2018 (favours concepts) and N = 2 studies exist; this is a human question outside our bench.
- Content of Linhares and Freitas (2010) critique was never read; needs the paper.
- Whether HiAgent-style gains hold with strong current models (HiAgent used GPT-4-turbo) and beyond a full-history baseline; needs U3.

## Order to run
1. **U5 (order of facts):** cheapest (reorder text only), clear prior of 15-22 points, and the result sets how every later memory test assembles context.
2. **U3 (subgoal-close summary):** three independent sources point the same way, so a replication in our scaffold decides a real schema change and costs only a prompt step.
3. **U1 (slotted vs flat notes):** the central new idea of the template theory, with the largest possible schema payoff and no LLM evidence yet; run it with U2 sharing the same items.
