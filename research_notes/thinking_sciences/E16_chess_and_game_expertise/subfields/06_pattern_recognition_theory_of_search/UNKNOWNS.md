## Open questions we cannot test on our bench yet
- LLM Einstellung at scale: needs paired trap items with a known short solution. Unblock: build the 40-pair set for U8.
- Small human samples (N = 4, N = 13, N = 25): need a larger modern study. We cannot run it; wait for outside replication.
- Search versus recall in LLM chess at equal tokens: needs a chess harness with fixed token budgets. Unblock: write a simple FEN task runner.
- Dual-task and working-memory findings: no LLM analogue. Unblock: none identified.
- Original sources (Charness 1976, Bradley 1987, Gobet and Simon 1996 numbers): paywalled or second-hand. Unblock: library access.
- Whether internal look-ahead (Jenner) appears in prompted LLMs: needs model internals. Unblock: probing an open-weight model.

## Order to run
1. U1 (recognition-first with escalation versus always-search): the core S0 claim; no direct test exists; cheap with existing bench arms.
2. U7 with U3 (foothold threshold and difficulty gate): same runs, cheap, established direction (K21); they give G12 its numbers.
3. U2 (signal-fired second pass on trap items): the main risk of a recognition-first design is Einstellung; it must pass before any fast path is trusted.
