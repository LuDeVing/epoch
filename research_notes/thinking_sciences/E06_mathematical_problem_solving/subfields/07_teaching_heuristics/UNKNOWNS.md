## Open questions we cannot test on our bench yet
- True human effect sizes for heuristic teaching: Hembree (1992) full text, Koichu et al. (2007) effect size, Schoenfeld 1979 (none given). Unblock: obtain the full texts and extract d, or skip, since they only set a prior.
- Delayed retention of taught heuristics in humans (Hohn and Frey 2002 not opened). No LLM test is a substitute; U9 covers only drift.
- Whether Schoenfeld's belief-system component has any agent analogue. Missing: a measurable agent "belief" about problem types. Unblock: a design for class-level priors.
- Heuristic versus schema/worked-example effect (K08) at equal tokens on humans. Unblock: a human study; for the agent, the nearest proxy is U8 and U13.
- Prompt-level evidence on reasoning models for diversity, verification with tools, and selection accuracy. Unblock: run U1, U4, U6 on the production core; no published study to lean on.
- Whether results from older models (GPT-3.5, PaLM-2, text-davinci) hold at all on the current core. Unblock: re-run the cheapest of them (U5, U7) on the current core before trusting any 2022-2024 number.

## Order to run
1. **U1 (heuristic block on/off at equal tokens).** Cheapest; settles whether any operator text should reach the core at all, and gates every other test.
2. **U2 (heuristic x control 2x2).** Tests the subfield's central claim, which no LLM ablation has separated, and decides whether the control layer or the operator list deserves the effort.
3. **U4 (operator selection by code vs by model).** Selection accuracy has never been measured, and the result decides how S6 picks operators.
