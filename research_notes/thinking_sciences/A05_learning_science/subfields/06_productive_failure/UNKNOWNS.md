## Open questions we cannot test on our bench yet
- **Study-level meta-analysis data** (lab share, domain, fidelity). Needs the full text or supplement of Sinha and Kapur (2021); Sage returned 403. Unblock by a library or author copy.
- **Kapur 2008, 2012, 2014 numbers.** Paywalled. Needed to know the original effect sizes. Unblock by access.
- **Retention beyond one week.** The bench has no long delay for an agent; a memory file does not forget. Only human studies bear on this, and none has a controlled delayed test above n=16.
- **Human motivation and effort mechanisms.** No analogue in a model.
- **PF for a model that can be fine-tuned.** Out of scope: our aim is a scaffold, not training. LeMa, NAT and multi-attempt RL are the only data.
- **Brand et al. 2024 and Kapur 2014 vicarious failure.** Not read; unblock by access. U3 would give our own answer for agents.
- **Whether the replication failures share a cause.** Human data cannot answer it. Agent traces of attempts, distinct methods and coverage (U4) give a partial answer for our items only.

## Order to run
1. **U2 (verifier dependence).** Cheapest and highest stakes: the evidence is already [E] in direction, and the result decides whether the lessons memory is safe at all without a check.
2. **U1 (attempt-then-lesson vs lesson-then-attempt).** The core PF claim for an agent; no one has run it at equal tokens, so a clear answer is new knowledge and decides the memory order rule.
3. **U10 (distilled lessons vs raw trajectories).** Shares the harness with U1 and U2, and decides the memory format, which every other lessons test depends on.
