## Open questions we cannot test on our bench yet

- Eye-movement markers (fixation length, element-level attention) have no LLM counterpart. Unblock: attention-attribution or tool-call logging that shows which elements an attempt used; start with element coverage per attempt (U9).
- The Miller, Wiley, Ohlsson cue study has no sample sizes, effect sizes or instruction wording. Unblock: library access or a copy from the authors; without wording we cannot copy the human cue design for U2.
- Ohlsson 1992 and the 2011 mechanism (K32) cannot be read. Unblock: library copy of the book chapter.
- Replication of the late sudden shift (K06) needs second human datasets (Tseng et al. 2014; Kershaw et al.). Not a bench test; only matters if we plan to time operators.
- A true A-D set with tightness labels for LLMs needs an independent tightness measure. Wu et al. 2017 is the only independent measure and is Chinese characters. Unblock: build tightness from model failure rates on single-unit edits (tokenizer dependent, d08).
- Hidden-state correctness probes (d12) need open weights. Unblock: run on an open model only to learn whether endorsement is the issue.
- Does progress monitoring or representational change better predict LLM failure? Needs lookahead-controlled items. Unblock: the progress monitoring subfield (04_progress_monitoring_theory) designs them.
- Net gain on ARC-type and NoveltyBench targets (K30) depends on those suites having verifiers per item. NoveltyBench has no single-answer check, so U1 and U6 cannot be scored there until a distinctness-based metric is agreed.
- Effects shrink with model strength (d18). Unblock: rerun every test above on the model we ship, not on the models in the literature.

## Order to run

1. **A12.01-U3** (selection share on our target sets): cheapest, uses logs we already have, and decides whether any representation operator is worth building on a class (K31).
2. **A12.01-U1** (named cue vs Wait vs resample): the missing head-to-head that decides the O4/O6 router design; a Wait-style arm is a strong cheap baseline (d10) and must be beaten.
3. **A12.01-U4** (fresh context with code summary vs continue): a single code change in S6 re-entry, indirect support is strong (d09, d10), and it also makes U1 and U7 results cleaner.
