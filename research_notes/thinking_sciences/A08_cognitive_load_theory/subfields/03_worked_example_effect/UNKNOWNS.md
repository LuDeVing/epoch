## Open questions we cannot test on our bench yet
- Exact Ns and effect sizes for Sweller and Cooper (1985), Schwonke et al. (2009), Salden et al. (2009). Blocked or paywalled. Unblock: full text via a library or the authors. Until then use only the Barbieri prior (g = 0.48, 55 studies) and treat it as a prior, not as an estimate for agents.
- Publication bias in Barbieri et al. Needs the full paper.
- A true load measure for LLMs. No accepted proxy for "extraneous load". Unblock: a study linking attention or token budget to accuracy at matched content.
- A matched human-protocol test in an LLM (examples vs bare problems, transfer test). None exists. Our own bench is the only route; U1 to U3 partly cover it.
- Learner outcomes from LLM-generated worked examples (test scores, not ratings). Needs a human-subject study.
- Whether newer reasoning models keep the full-trace harm. One preprint with plots only. Unblock: rerun on our reasoning model (U2).
- Element interactivity for agent subgoals, estimated before the result. Unblock: define a count of dependent sub-steps and test it as the gate signal in U1.
- Tasks with no fixed procedure (open mode). Human evidence is snippets only (Nievelstein 2013, Rourke and Sweller 2009). Unblock: an open-mode bench with human-rated novelty, outside this note.

## Order to run
1. **A08.03-U1 (gate by failure).** Cheapest and highest stakes: it decides whether the library is on by default, and three sources (human and LLM) point the same way.
2. **A08.03-U2 (note vs full trace on a reasoning model).** The largest measured effect in the whole file (up to 35 AIME points of harm) and it fixes the entry format before any library is built.
3. **A08.03-U4 (admission gate and retirement).** Large measured gaps (16.75, 13.05, 38.50) on records, and the library cannot be filled safely until this is settled. Run U3 (k sweep) in the same session since it shares the setup.
