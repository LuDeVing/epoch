## Open questions we cannot test on our bench yet

- **Human replication of Nievelstein 2013.** Needs students and a legal-reasoning test. Would unblock: cite human evidence at [E] instead of [S]. Cheapest route is a literature scan with a fresh citation search once rate limits ease.
- **A trusted judge for open-task quality.** Ill-defined benchmarks give weak signal (Zhou and Shbita, d12), and model judges favour length and their own style (G5, G8). Needs a small human-rated panel of 80-200 items to calibrate any judge. Without it, U1-U4 and U9 results are weak.
- **Pre-registered task labels for "ill-structured".** We have no agreed list of items with human-assigned structuredness. Needed for U7. Would unblock: a labelled set built from our bench plus public sets (dilemmas, case analysis, design).
- **Skill vs topic in LLM examples.** No study varies example content independently of the named skill (critique gap 4). Needs a factorial item set that crosses skill with topic. Cheap to build once U2 is done.
- **Reasoning-model behaviour in 2025-2026 on soft tasks.** The Sprague and Liu results are on older models. Needs reruns with the models we use. Folded into U8 and U4 if they run on current models.
- **Misrouting cost.** Unmeasured until the S0 route is logged on real runs (N6 in DEEP.md). Needs one batch of logged runs.
- **Dose and similarity on open-form items.** No data for distant examples. U6 fills part of it.
- **Individual-difference analogues.** Whether sensitivity to representation change plays the role of shifting ability has no operational definition yet.

## Order to run

1. **U9 (diversity method head to head).** Every method already has established support, only the comparison is missing, and it decides the default for open-mode S3 at low cost.
2. **U2 (named skill steps vs example vs both).** The best-supported candidate for open-task support without examples, and it also answers the example question for U1 in the same item set.
3. **U4 (silent vs written steps).** Cheap prompt change, a single run on the same items, and it decides whether visible reasoning belongs in open mode at all (G11).

Run U7 (S0 routing) right after, because every later result depends on being able to say which items are open.
