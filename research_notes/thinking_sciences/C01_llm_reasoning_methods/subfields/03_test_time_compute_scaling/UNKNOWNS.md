## Open questions we cannot test on our bench yet

- **Logprob-based stop rules (DEER, DeepConf).** Need token probabilities and trial-answer scoring. Unblock: an API or local model exposing logprobs.
- **Budget forcing proper (s1).** Needs control of the end-of-thinking token and a fine-tuned model. Unblock: a local open model, or an API thinking-budget parameter with a pause-and-resume mode.
- **PRM-guided search and the Snell recipe with oracle bins.** Needs a process reward model and thousands of samples per item. Unblock: a step verifier for one task class, or a large offline sample set.
- **Independent replication of small-beats-large (Liu).** Needs the same pair and a weak PRM. Unblock: one open small/large pair and a trained reward model.
- **Equal-total-token accounting including verifier tokens.** Few papers report it. Unblock: bench logging that counts every call (needed for G7 anyway).
- **Open-ended tasks.** No evidence on tasks without a checkable answer; learned allocation saved only 0-10% on chat (d03). Unblock: a rubric or human-graded set, plus a selector other than vote.
- **Benchmark contamination (405B: 40% on old AIME-style vs 1% on 2025 questions).** Unblock: fresh, post-cutoff item sets in our bench.
- **Whether self-correction results from GPT-3.5/4 hold for current reasoning models.** Unblock: run U5 on our current model.
- **Frontier closed models with built-in thinking budgets.** Evidence is thin beyond Gema 2025 and GAIA with GPT-4.1. Unblock: our own runs (U1).

## Order to run

1. **U5 (verifier error and N cap).** Cheapest and it gates everything else: every sample-heavy or loop rule needs the measured FP/FN rates first.
2. **U1 (extended vs parallel by difficulty).** Resolves the largest contested claim (K09) and decides the default mode in S0 and G11.
3. **U2 (probe-gated difficulty).** Biggest expected token saving for the S0 gate; reuse the U1 item bins and U5 logs, so the marginal cost is low. U3 and U4 can follow on the same item set.
