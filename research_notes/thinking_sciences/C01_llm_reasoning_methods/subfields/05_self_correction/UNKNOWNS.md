## Open questions we cannot test on our bench yet
- Prompt-only match for SCoRe or RISE on open models. Nothing published. Unblock: an open model with a training budget, which is out of scope for the scaffold.
- Whether natural errors behave like Tsui's injected errors. Unblock: a set of natural wrong drafts with gold error labels from our own runs.
- Frontier long-CoT models at equal tokens against best-of-n for revision. Unblock: API budget for 3+ seeds on a reasoning model and a fixed token meter.
- The size of the Liu vs Huang gap. Unblock: the original prompts and model versions (gpt-3.5-0301 and 0613), no longer served.
- Whether SCoRe's base fix rate is 4.6% or 9.5%, and RISE's no-oracle numbers. Unblock: author code or tables.
- Open-ended agent work: ProcessBench and BIG-Bench Mistake have gold step labels, agent steps do not. Unblock: human-labelled first-error steps on a sample of agent traces.
- Li et al. Figure 4 flip numbers (unreadable). Unblock: the source figure or rerun.
- A human-in-the-loop feedback condition (Olausson 52.6% vs 33.3%). Unblock: a human labeller; not a scaffold feature.

## Order to run
1. **C01.05-U4** (neutral check vs no check, seeds and CIs): cheapest, and its answer sets the base rate for every other revise test.
2. **C01.05-U1** (bigger first solve vs check call): if a longer first solve matches the check, S5 shrinks and tokens go to S3.
3. **C01.05-U2** (draft as another solver's answer): one prompt change, large possible effect on every S5 step, single-source so far.
