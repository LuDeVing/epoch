## Open questions we cannot test on our bench yet

- **Real multi-step agent with interfering memories.** All LLM evidence is synthetic key-value or QA. Unblock: build a bench task family where lessons accumulate across episodes (needs the lesson library harness and class labels).
- **Primary human numbers.** Wickens 1963/1970, Keppel and Underwood 1962 tables, Underwood and Ekstrand were not opened. Unblock: fetch the primaries if we want to quote effect sizes; not needed for the design.
- **Why the strongest models close the PI/RI gap.** Training or test artifact? Cannot test without model internals. Unblock: only run the paired RI/PI test (U9) on each model we use.
- **Bimodal PI at N>=200.** Sampling or format? Unblock: repeat sessions with different formats and seeds (cheap, low value for the schema).
- **Mechanism (attention sink, superposition).** Claims are post hoc. Unblock: needs access to attention maps; not available with API models.
- **Similarity as the driver.** MINTEval found out-of-domain distractors hurt RAG most. Unblock: a controlled test with similarity measured by one embedder, varied independently of domain.
- **Search gaps.** The 2026 paper sweep was cut short (quota). Unblock: rerun searches for category-shift release, entry compression and per-class caps when search budget returns.
- **Training-based fixes (SleepGate, Sculptor RL).** Not applicable to a scaffold; no unblock needed.

## Order to run

1. **A06.03-U1 (cap per class) with the sweep from U7 folded in:** it is the one item in the original "why it matters" line that no paper has tested, and the cheapest to build (only the retrieval list changes).
2. **A06.03-U2 (hide vs tag vs delete superseded):** the biggest measured effect (+23 to +33 points) and an easy rule; we only need the head-to-head to pick the form.
3. **A06.03-U3 (category release for LLMs):** strong human evidence, zero LLM evidence, and the same harness as U1 (class labels), so the marginal cost is small.
