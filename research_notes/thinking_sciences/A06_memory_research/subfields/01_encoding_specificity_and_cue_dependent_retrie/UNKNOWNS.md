## Open questions we cannot test on our bench yet

- Founding numbers (Tulving and Osler 1968, Tulving and Thomson 1973, Godden and Baddeley 1975): papers paywalled and not opened. Unblock: library access or a verified PDF.
- Whether the diver effect is real: needs a second independent close replication. Not our bench; no design change depends on it.
- Whether frontier models reproduce a Thomson-Tulving design (studied weak cue vs unstudied strong cue): needs a purpose-built list task with a frontier model and controlled context length. Not a lesson-memory test, so low value.
- Whether humans' report-criterion effect has an LLM counterpart: needs calibrated token-probability access, which our harness does not expose.
- Long-term effects of lesson libraries over hundreds of problems (cue drift, fan growth): needs a long run with real logged lessons; our lesson store is small so far.
- Cue effects in non-text agent memory (code, graph, subgoal library): needs the subgoal library (SCHEMA section 7) to exist.

## Order to run

1. A06.01-U1 (enrichment vs random-token control): cheapest, and it settles the contested claim K10 that decides whether write-time key work is worth any tokens.
2. A06.01-U3 (hard-distractor cost and fit check): the harm is established in QA readers, the fix is one line, and it protects every other memory test.
3. A06.01-U9 (unique vs matching keys): decides how lesson keys are designed, with fan controlled; reuses the same lesson set as U1.
