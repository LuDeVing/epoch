## Open questions we cannot test on our bench yet

- Human replication of Gick and Holyoak (1980, 1983), Gentner et al. (1993) and Ross (1984) at modern sample size. We never opened the originals. Unblock: obtain the PDFs and read the tables; a Many-Labs-style replication would be needed for a size estimate.
- Adaptation-guided retrieval as originally defined (Smyth and Keane 1998). Unblock: open the paper, then define an edit-cost measure for our subgoals (see U14).
- Contamination-free evaluation. Needs problems written after every tested model's cutoff and a way to date them. Unblock: build a small fresh item set by hand or from new competitions.
- Long-run library growth (thousands of subgoals), forgetting and drift. Our bench runs are short. Unblock: a streaming run with a frozen test set checked at intervals.
- Independent replication of the own-group LLM results (ExpeL, Memento, ReasoningBank, Memp, CASCADE). Needs their code and their benchmarks; partly possible on ALFWorld only.
- Interaction of the library with test-time compute scaling and with voting (G4, G9). Unblock: run U1 under both single-sample and best-of-N arms at equal tokens.
- Cross-domain structural retrieval (does a relation label retrieve a distant analog for an LLM?). No LLM study; human result only (Raynal 2026). Unblock: build a small set of structurally matched, surface-different subgoal pairs.
- Whether a stored case's explanation (not only its solution) changes use. Kolodner argued for showing failed cases with explanations. Untested on LLMs.

## Order to run

1. U1 (subgoal library vs none vs random vs whole-task): the central gap; every other row depends on a library existing and winning at equal tokens.
2. U3 (wrong-case dose-response with verified vs model-judged admission): cheap to run once the library exists, and it decides how strict the Retain gate must be.
3. U2 (retrieval key: raw text vs description vs success-weighted rank): reuses the U1 library with one switch, and the key is the strongest lever in the evidence.
