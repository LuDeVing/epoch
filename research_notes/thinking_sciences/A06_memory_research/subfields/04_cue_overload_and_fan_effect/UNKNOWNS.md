## Open questions we cannot test on our bench yet

- **Frontier fan slope in natural text.** Needs the sweep U2 on a large enough library. Missing: a library with many truly related notes per cue; today we have few. Unblock: generate a synthetic but meaningful library from our own lessons, validated by hand.
- **Original numbers of Watkins and Watkins (1975) and Anderson (1974).** Blocked by paywall and a Cloudflare check (d22, d23). Unblock: a library copy or interlibrary request. Does not change the schema; it only fixes quotations.
- **Independent replication of the Guo et al. log-fan result.** Needs a human sample at fan 1 to 16 or an LLM-reader run at the same fans. U2 covers the LLM side only. Provenance of the preprint (id 2606 vs date May 2026) is odd.
- **Human integration boundary in LLMs.** The human literature itself is contested (K13). Unblock: wait for a replication, or run U5 as the only test.
- **MRCR-style 2/4/8-needle sweep per model.** The dataset card gives no per-needle accuracy, and the aggregator numbers are not lab reports. Unblock: run the open MRCR data ourselves on the deployed model.
- **Token probabilities.** U7 needs logprobs from the deployed model. If the provider hides them, a proxy open model is needed (an extra call).
- **Size dispute (Wang and Sun vs Chattaraj and Raj).** Needs the same tasks and models in one study. We test only our own model (U11).
- **Real, non-synthetic overwrites at scale.** The 164 real-world DKIs average 8.77 length (c09); the Supersede set has n=78. Unblock: build overwrite items from our own run logs.
- **Hit rates vs false alarms in LLM recognition.** No LLM data beyond fan 2. U2 and U9 will give it.

## Order to run

1. **U2 (fan curve, N = 1 to 50, log vs power).** It is cheap, it uses no new code, and it sets the size of every other effect: if our model shows no loss up to N=16, U1, U3 and U4 are not worth building.
2. **U1 (replace vs append-only, setup cost counted).** Highest expected gain and the most contested claim (K31); the only evidence is synthetic or uncontrolled, and G7 requires it.
3. **U3 (k sweep and code prefilter).** Cheapest to run, uses the same library as U2, and the only established part (K27) says the answer is reader-specific, so we must measure it on our reader.
