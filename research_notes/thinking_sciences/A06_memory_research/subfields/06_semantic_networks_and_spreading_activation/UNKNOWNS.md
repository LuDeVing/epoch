## Open questions we cannot test on our bench yet

- Millions of nodes: we have no memory that large. Unblock by replaying a long public log (for example LongMemEval-S style histories) or by generating a synthetic one. Nothing is tested above about 314k nodes (d03).
- Human rank effects in embedding neighbours (K06, a15): needs an item set with known primary associates and an embedding space. Unblock by using SPP/SWOW norms as the gold set for an embedding-neighbour probe.
- Whether biased LLM association graphs change retrieval output (K30): no retrieval study exists, and the paper named in the gap list was not found. Unblock with a before/after audit on our own graph (U11).
- Independent replication of SYNAPSE (K17): code was promised on acceptance. Unblock when the code is released, or by building the formula ourselves and comparing with equal-length baselines.
- Whether the human automatic/strategic split has a counterpart in LLM loops (K04): no SOA exists. Unblock by treating "code pass vs model pass" as the split and measuring tokens saved.
- Mediated priming disagreement (K03): human only and not needed for the agent. Skip unless depth tests (B3) show an unexplained gain at hop 3.
- Pure meaning vs association edges (K05): disputed in humans. Needs the edge-type test (U6) to say anything for agents.
- Router training on free-form thoughts (U2): needs labelled logs of which method won per thought. Unblock by logging both arms on a few hundred items.
- Opening the original 1969-1983 papers: paywalled, so theory details are secondhand. Low value; skip unless a detail from them is needed.

## Order to run

1. U1 (with U13): spread vs dense vs dense + rewrite at equal tokens. It is the biggest open gap (K31) and decides whether spread stays in S3 at all.
2. U2: rule router. If spread helps only on multi-hop, the router is what makes it free on single-hop, and it is cheap code.
3. U3 (seeding): the largest single effect in the ablations (12.5 to 27.5 recall points), cheap to run on the same items as U1.
