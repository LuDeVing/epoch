## Open questions we cannot test on our bench yet

- **Wald and Wald-Wolfowitz proofs for dependent vote streams.** Needs the original papers (publisher blocked). Unblock: obtain the PDFs from a library or the author repository, or find a modern proof of optimality under dependence. Until then, never quote "half the samples" or any error guarantee.
- **Anytime-valid certificates tighter than 3-25% savings.** No method gives a rigorous guarantee with large savings for correlated LLM samples. Unblock: theory work, not a bench test.
- **Frontier models behind hidden log-probs.** Token-confidence methods cannot be run on hosted models. Unblock: an engine with log-probs, or a hosted API that returns them.
- **Open-ended and agent stopping.** No paper tests it. Unblock: a validated same-outcome judge (U10) and a set of open items with human labels.
- **Cost accounting in tokens, calls and wall time together.** Published papers report one. Unblock: log all four on our bench from now on.
- **Independent replication of ConSol.** Needs another group, or our own run (U1, U2) with more seeds and a wide sweep.
- **Correlated errors within one model.** Only cross-model data exist (d12). Unblock: U3.
- **Classical numbers read from memory** (Armitage 14% / 19%, Pocock 0.0158, Bassler 0.71). Unblock: open the sources before quoting.

## Order to run

1. **U4 plus U1 together (small-budget and head-to-head stop rules)**: cheapest, same items and samples, and tells us whether any stop rule beats a plain fixed-5 or fixed-8 at equal tokens. If not, most of this subfield drops out.
2. **U3 (seeded wrong consensus)**: the largest unmeasured risk. It decides whether an agreement stop is allowed without an independent check.
3. **U8 (verify-stop vs agree-stop)**: reuses the same samples where a checker exists, and sets the default for every item type that has tests.
