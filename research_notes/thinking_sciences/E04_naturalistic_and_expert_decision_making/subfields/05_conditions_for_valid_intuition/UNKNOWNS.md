## Open questions we cannot test on our bench yet

- **Real feedback delay.** Bench grading is immediate. K&K's "rapid and unequivocal" condition needs tasks where the true outcome arrives later or is ambiguous. Unblock: a bench class with delayed grading or noisy human labels (K&K a05; d06 limits).
- **Wicked feedback (agent-influenced grades).** We lack a task where the agent's own action shapes the label, so the independence flag cannot be validated. Unblock: a simulated environment with self-fulfilling outcomes (a18, b04).
- **Cue validity as a measured quantity.** No scale exists. We can measure first-answer hit rate against base rate, but not validity before data. Unblock: a set of synthetic classes with controlled cue-outcome correlation (r from 0 to 0.9) so we can see how the record behaves.
- **Persistence of skill across model versions.** The record is model-specific (c13, c17). Needs repeated runs over several model versions. Unblock: re-run tests U1, U2 on each new model.
- **Premortem or second look as a human-validated move.** No outcome data (a12). Unblock: read forecasting and medical-error studies; none found yet.
- **Superforecaster persistence and training after the 2025 reanalysis.** Abstract only (d11). Unblock: open the full paper and Mellers 2015.
- **Whether the human clinical-versus-actuarial gap says anything about LLMs.** Needs a head-to-head on a real prediction task with ground truth. Copus (c24) is the only attempt and is abstract-only.
- **Frontier-model calibration claims.** Michael 2026 is a summary page (c06, c07). Unblock: read the full paper and rerun on our models.
- **Rebuttals to the Apple puzzle study** (d09). Not opened; the collapse point is unclear.
- **Sequential-testing rule for "enough cases".** No source. Unblock: a statistics source on sequential tests for a Bernoulli rate, then test in U3.

## Order to run

1. **E04.05-U1 with U2 on the same data.** It is the S0 gate itself. U2 tells us which signal to feed it. It is cheap because the class records come from logs we already write (SCHEMA section 6).
2. **E04.05-U9 (mode per class).** It decides direct vs CoT vs thinking, which sets how much the gate can save. It reuses existing arms (plain, checked, scaffold).
3. **E04.05-U3 (sample-size sweep).** It gives the missing thresholds, and it is a replay of U1 data at different n, so it costs almost nothing extra.
