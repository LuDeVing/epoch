## Open questions we cannot test on our bench yet
- Independent-lab human effect sizes for directed exploration (Gershman 2018, Chakroun 2020, Somerville 2017). Needs full texts opened. Does not change the agent unless U4 shows an effect.
- Whether an LLM can estimate answer partitions over overlapping or soft answers as well as sampled hypotheses. Needs an item set with soft answers and a gold answer model.
- Friston-style insight (prune the hypothesis space and commit) in LLMs. Needs a task with a hypothesis space that provably contains the answer. Links to the cognitive-conflict and search-over-thoughts subfields.
- An isolated test of the active-inference switch (epistemic to pragmatic) in an LLM. Needs U6 first, plus a clean belief state.
- Whether information gain tracks real value when the hypothesis set is only as open as the LLM's imagination (Kobalczyk limit). Needs items where the true answer is outside the sampled set.
- Whether the 38.1% UoT figure is relative or in points. Needs the authors' table or code.
- Equal-token tests of tree-search scaffolds with epistemic scoring. Needs the Tree of Thoughts and Language Agent Tree Search subfields to land.

## Order to run
1. B03.05-U2 (tally and forced sweep): cheapest, largest evidence so far, and it decides how much of the rest matters on current models.
2. B03.05-U1 (stop on gain vs fixed budget): the central claim of this subfield, untested for open probes, and it saves tokens if it works.
3. B03.05-U3 (open-set EIG with sampled hypotheses): decides whether probe scoring by code is worth adding beyond the tally.
