## Open questions we cannot test on our bench yet

- **Human replication of Ko and Uttl.** Needs human participants and an unfamiliar tool. Unblock: skip, test only the agent version (U7).
- **Pennington's order in agents.** We have no clean way to ask for "program model only" and "situation model only" and score them on comparable questions; Burkhardt notes the same calibration problem. Unblock: build paired control-flow and function questions of matched difficulty.
- **Primary texts of Brooks 1983, Letovsky 1986, Littman 1986, Gilmore 1991.** Never opened. Unblock: library access; check whether they add rules beyond d14.
- **Equal-token comparison across reading units** (skeleton, 100-line window, call graph). Existing studies use different harnesses. Unblock: one harness with a unit switch (U1 can carry it).
- **Model-uncertainty triggers** (ICLR 2026 snippet, d19). Not opened. Unblock: open the paper and decide if it is a rival to U8.
- **Contamination.** Most LLM numbers are single benchmarks that may be in training data. Unblock: use fresh or private repo items.
- **Whether LLM gains from structure scale with repo size.** Lin et al. say density and hub-heaviness matter. Unblock: items grouped by repo size.
- **Breadth-first vs depth-first for agents is bundled with other changes in SWE-Adept** (d12). Unblock: ablation in our harness (U7).
- **Does reasoning-tuned versus coder-tuned model type change which reading prompt works** (c13 abstract only). Unblock: run U1 on both kinds of model.

## Order to run

1. **U3 (execute vs simulate).** Cheap, uses tools we already have, and it decides how much of S2/S4 should be a code check. The evidence conflicts (c14, c15 vs d04), so the answer moves the schema either way.
2. **U1 (strategy prompts vs plain).** The central gap: no one has tested the human models as prompts. One run answers whether this whole subfield matters for the agent. U6, U7 and U14 can reuse its harness.
3. **U4 (code first, comments as claims).** High expected gain (13.8-23.2% loss in output prediction), cheap to build with planted wrong comments, and it settles a contested claim (K14/K27).
