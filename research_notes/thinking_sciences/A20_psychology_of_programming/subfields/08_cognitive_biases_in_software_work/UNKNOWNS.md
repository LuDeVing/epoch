## Open questions we cannot test on our bench yet
- **Randomised human trial of logic or hypothesis-testing training in software testers.** Needs human participants. We rely on non-software trials (Branchini, d12; Sellier, d13). Unblock: none needed for the agent, treat as a hypothesis for it.
- **Replication of Calikli 2010 and the PROMISE 2010 and 2015 numbers.** Full texts were blocked. Unblock: institutional access or the authors' data.
- **Leventhal 1994 numbers on spec completeness and domain knowledge.** Only abstracts seen. Unblock: the full paper.
- **Frontier reasoning models on failed-attempt contamination.** Existing studies use 1.5B to 70B models. Unblock: run U2 on our base model.
- **Share of generated specs that inherit the bug as a rate.** Only injected cases and Zhao's 15-21% on Java. Unblock: a seeded-bug set where the spec is generated from the buggy code.
- **A common bias probe across SynAnchors, Kraishan and AnchorBench.** Metrics differ. Unblock: build one probe and run it on our model (feeds U7).
- **Defect link to confirmation bias in humans.** Five developers, twelve testers. Needs a larger field dataset.
- **Whether LLM bias scores on vignettes predict behaviour in a code loop.** No bridge study. Unblock: pair a vignette probe with U1 on the same model.
- **Axiomatic cue cost on frontier models.** Wide CIs and cheap models only. Unblock: U4.

## Order to run
1. **U1 (forced falsification slot).** The core G3 question, cheap to build (one extra slot), and the best-supported lever on rule tasks; code transfer is the one missing link.
2. **U2 (clean-context retry).** Costs less than the current retry (fewer tokens), and the literature splits by model size, so only our own data can settle it.
3. **U3 (code-hidden spec tests).** Largest reported effect (+38 pp) and the cleanest design gap; reuses the same test harness as U1.
