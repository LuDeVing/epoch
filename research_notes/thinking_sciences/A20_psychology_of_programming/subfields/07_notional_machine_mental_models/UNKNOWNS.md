## Open questions we cannot test on our bench yet

- **Independent replication of NM teaching with N above 100.** Needs human classroom data. We cannot run it. We only have PLTutor (N=18 vs 19) and one null (N=48, abstract only).
- **Whether the rule sheet matters across languages.** Our bench items may all be Python. We need items in a second language (JavaScript, Java) with different reference and scoping rules.
- **Real-student misconceptions in LLM tests.** Misconception data (a29, b14) come from LLM-injected bugs. A set of real novice code is needed.
- **Equal-token trace cost table.** We need token counts by executed lines for state-table traces and for code-run, to find the break-even line count. No paper gives it.
- **Frontier reasoning models on scaffolded tracing.** Most numbers are from 2021-2024 models. Modern models trace at 85-98% and may not need any rule sheet. We need our own baseline first to see if there is headroom.
- **Faithfulness of reasoning traces on reference semantics.** Needs a probe set that separates "reasoned correctly" from "right by pattern". Coherence judging (b12) used an LLM judge, which G5/G8 distrust.
- **Original definitions.** du Boulay 1981 and 1986 and Sorva 2013 were not opened. No effect on tests, but quoting needs checking.

## Order to run

1. **U4 (code-run vs in-head, break-even line count).** Cheapest, largest expected gain (15+ points), and sets the rule that U2, U3, U5 and U8 depend on.
2. **U2 (real trace in the revision slot).** Directly changes S5 and G2 for code items; the code harness already runs programs.
3. **U1 (rule sheet for edge semantics, with ordinary items scored too).** The real question for S2 and the largest gap in the literature; the single data point (d13) shows both a big gain and an over-trigger cost.
