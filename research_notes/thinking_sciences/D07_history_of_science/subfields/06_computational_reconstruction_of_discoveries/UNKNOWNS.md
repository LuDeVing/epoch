## Open questions we cannot test on our bench yet
- Human bars for Kepler-style discovery (Qin and Simon 1990) and the 1999 review: needs the papers; paywalled. Unblock by a library copy or author pages. Until then K26 stays unverified.
- Historical-order case series with wrong turns marked: needs a curated case series with the original data and recorded errors, and a scoring rule for wrong turns. Unblock by building a small series (three to five episodes) with a domain expert.
- Real-world noisy data and true unknowns: our bench has clean generated items. Unblock with a held-out real dataset where the law is not on the web.
- Peer-review status of the 2026 preprints (SciLaws-Bench, library reachability, LLM-PySR, IGSR): wait for review, or re-run their code on our items.
- Whether results on equation tasks carry to word and logic problems: needs a bridge item set with the same check structure in both forms.
- Independent replication of AI Feynman, LaSR and LLM-SR on a shared recall-controlled set with code-based equivalence: needs an equivalence checker (symbolic simplification) in code; build once.
- Why code hurts strong models: reading reasoning traces is not an intervention. Unblock only with U2-style rules or with trace-level logging of the first code call.
- Credit for the model's own judge on symbolic equivalence: needs a code-based equivalence check before any LLM-judged numbers from the literature can be trusted.

## Order to run
1. **U3 (scaffold vs plain reasoning model with code, equal tokens, invented laws).** It is the missing arm; every other test only matters if the loop pays at all on a strong backbone.
2. **U1 (held-out check before submit).** Cheapest to build on the same item set and the best-supported lead: selection is the weak step and it is untested.
3. **U2 (minimum-hypotheses rule against code access).** One extra arm on the same items; it tests the only explanation we have for why tools hurt strong models.
Run U4 alongside U3 as a standing control arm at no extra item cost.
