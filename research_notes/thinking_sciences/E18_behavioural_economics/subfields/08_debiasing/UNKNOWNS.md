## Open questions we cannot test on our bench yet

- **Independent human replication beyond 8 weeks, with a non-video comparator.** Needs human subjects; we cannot run it. Without it the "feedback transfers" principle (U6) stays an analogy.
- **Frontier reasoning models (Claude and GPT-5-class thinking) at budgets above about 3,500 tokens.** Needs access and budget; U4 covers what we can reach. Huang and Kraishan may differ because of the metric, so a shared metric would unblock it.
- **A classifier for missing-rule vs intuition-type LLM errors.** Needs a labelled item set (Aczel-style). Build the labels by hand for 100 items first, then U1 can use them.
- **Role-diverse debate with different model families (DReaMAD, MoLaCE) vs a single debiased pass.** Needs several model families and a matched-token harness. Until then G9 stands.
- **Real decision outcomes.** Human and LLM studies measure bias gaps, not decision value. Need tasks with ground truth (forecast resolution, code correctness) to link bias gap to accuracy.
- **Paraphrase variance of bias scores.** Not re-measured in this study; B12 is the pilot.
- **Whether the Sanna backfire (listing many alternatives raises certainty) has an LLM analogue.** No test exists; add a "2 reasons vs 6 reasons" arm to U7.
- **Weights-level fixes (steering, Anti-DP, fine-tuning).** Cannot test without weight access; irrelevant to a scaffold (K21).

## Order to run

1. **U12 plus B12 (baseline and power pilot).** Cheap, gates everything: it tells us which biases our agent has, in which direction, and how many items we need. Without it later tests are underpowered (K31).
2. **U1 (rule elicitation).** Best-supported LLM prompt fix and the only one that directly tests the missing-rule split; likely biggest gain per token.
3. **U2 (input rewrite vs instruction).** Cheap, fits S1 already, and tests the main contrast between changing the input and adding instructions.

Then U3 and U4 (equal-token tests of the loop and of thinking budget), then U5.
