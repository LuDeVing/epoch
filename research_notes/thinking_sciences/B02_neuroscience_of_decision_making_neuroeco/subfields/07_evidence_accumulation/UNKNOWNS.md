## Open questions we cannot test on our bench yet

- **Confident-wrong rate on frontier or closed reasoning models.** Needs the same 16 warm-up log-probs we may not get from a hosted model. Unblocked by a model that exposes token log-probs, or by a black-box proxy (agreement only).
- **Faithful logLR reading of the bound (Gold and Shadlen 2007, Ratcliff 1978).** Neither was opened. Needs the papers (library access). Until then the Beta bound is a heuristic with a cap.
- **Head-to-head of stop controllers inside an agent loop.** Only one null exists (Vats, 21 tasks). Needs a larger agent task set with tests and a second controller design.
- **Stop rules for non-verifiable work** (research, planning). No ground truth for accuracy; needs a human-rated set or a trustworthy blind judge.
- **Practice effects.** Humans' fixed vs collapsing bound shifts with practice. An agent that learns bounds per class would need a long logged history in the class record before this can be tested.
- **Cost accounting across units.** Papers use samples, tokens and chain steps. We need our logs to carry all three per item before any published saving can be compared with ours.
- **Independence.** A measured correlation of wrong answers between samples of one model (shared-error rate) is not in any source. Needs the U3 log plus a second model as a reference.

## Order to run

1. **U3 (confident-wrong audit), with U1 on the same logs:** it produces the one number no source has, and it decides whether the Beta stop is safe on mid and hard items. U1 costs nothing extra.
2. **U7 (verifier vs agreement at equal tokens):** the only large untested gap in a result that already holds at equal sample count, and most of our checked-mode items have a held-out check.
3. **U5 (starting-bound signal):** cheap, replayable, and the gain from a good triage compounds with every other stopping rule.
