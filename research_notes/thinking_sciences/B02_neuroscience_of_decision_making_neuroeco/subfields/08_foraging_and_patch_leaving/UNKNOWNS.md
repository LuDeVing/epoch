## Open questions we cannot test on our bench yet
- White-box signals (J-space depletion, steering, probes): need open weights and lens or probe training. Unblock: run a small open model on a side bench. Note the natural-data probe AUROC is only 0.57 (c02).
- Reward per reasoning step: the bench scores final answers, not step yields. Unblock: add intermediate verifiers (code checks, partial-credit constraints) for a subset of items.
- A true depleting-reward task for an LLM (Kolling or Constantino-Daw style): none exists. Unblock: build a synthetic task where an answer pool shrinks, with a known optimal leave time.
- Human-style travel time in seconds: not meaningful. Need a token-cost analogue and a check that it behaves alike.
- Founding sources (Charnov 1976, Stephens and Krebs, Hills 2012, Hutchinson 2008): not opened. Unblock: read them before citing exact rules.
- Cortisol, dopamine, apathy, adversity effects (K08): not testable on an LLM.
- The dACC dispute (K06): should not matter for the agent; no test planned.
- Stop behaviour of frontier reasoning models on the yield curve: the overthinking papers used open or distilled models. Unblock: log reasoning length vs correctness for the bench's own model.

## Order to run
1. **U1 (rate trigger vs fixed-step vs sufficiency).** It is the S6 core and nobody has tested it; every other row builds on its arms.
2. **U4 (dwell floor) with U3 (patience margin).** Cheap sweeps on the same runs; they show whether the trigger is safe on hard items and set its threshold.
3. **U5 (code-computed yield vs model-estimated yield).** Decides whether the model can read the signal or code must fire the leave, which changes how U1 is built.
