## Open questions we cannot test on our bench yet
- **Founding human numbers.** Wegner, Erber and Raymond (1991), Liang, Moreland and Argote (1995), Hollingshead (1998) are paywalled. Unblock: obtain the PDFs or an open secondary source with counts. Low priority for the schema.
- **Directory ablation inside a multi-agent LLM loop.** No published study; we would have to build a multi-source environment with sources of truly different competence. Unblock: a synthetic environment with three tools of known, different accuracy per task class.
- **MATM replication on code, math or planning.** No independent group. Unblock: our own store test (U3, U5) is the closest we can run.
- **Is CoThinker's gain a compression effect?** Needs their code and a matched-compute best-of-N run.
- **Predicting the sign of dissent.** No rule linking baseline pooling accuracy to sign; needs several backbones, which we may not have.
- **Sparrow Experiments 3-4 (where versus what).** Never replicated; no value for the schema until someone does.
- **Credibility with deliberately wrong sources.** Nobody tested provenance tags directly; partly covered by U4 and U12.
- **Multi-agent settings.** Our agent is a single scaffold. Team-level findings (HiddenBench, Consilience) apply only to forced splits, which we mostly avoid; no test of whether we will need splits at long context.

## Order to run
1. **A17.10-U3 (verified-only lesson store versus add-all and no-memory)**, with U5 near-duplicate removal built in: cheapest, uses existing items, and decides whether the memory section of the schema should hold a store at all.
2. **A17.10-U2 (code injection versus optional lookup):** very cheap, one-line change, and tells us whether any memory we add is even used.
3. **A17.10-U1 (outcome-updated competence table for operator and mode choice):** the highest-upside new element (S0 gate and S6 operator choice are open slots in SCHEMA section 7), and the only one with two independent supporting groups.
