## Open questions we cannot test on our bench yet

- **Schon's own predictions (naming, framing, back-talk) against an LLM.** No coded design tasks with ground truth exist in our bench. Unblocked by building a small design-like item set with human-coded back-talk events.
- **Human back-talk rate beyond one architect (28%).** Needs a multi-designer protocol study. Not ours to run; look for replications (Bilda 2006 and later) when full texts can be reached.
- **What Schon's Quist and Petra case counts.** Needs the book. Low value for the agent.
- **Whether back-talk predicts design quality.** Mejia 2018 (N=2) cannot say. Needs a human study with outcome ratings.
- **Frontier models with thinking budgets varied, Huang setup.** Depends on API access to budget controls and thinking-token accounting; U7 covers what we can reach.
- **Prefill of the assistant turn ("Wait" as in Tsui).** Most closed APIs do not allow it. Only the instruction-text version (U3 and U4) can be tested.
- **Open design-like tasks with a trusted outcome measure.** Need blind human raters or a validated rubric; U10 uses two raters as a stopgap.
- **Time and cost of human feedback.** Olausson's human-feedback result (52.6% vs 33.3%) did not track human time. Matters only if we ever add a human in the loop.

## Order to run

1. **U1 (S5 vs best-of-N at equal tokens).** It decides whether the whole revise state earns its tokens (G7); everything else in this file only matters if the answer is yes.
2. **U2 (flag vs flag + program text vs flag + lesson).** Cheap, reuses U1's failed items, and decides whether the lesson text and the lesson memory stay.
3. **U3 and U4 together (marker and other-author framing).** Two prompt wordings run on the same failed-check items at no extra calls; the 89.3% blind-spot cut in Tsui is the largest prompt-only effect found.
