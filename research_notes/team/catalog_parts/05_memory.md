## memory

| ID | Mechanism | Claim | Evidence | Maps to | Agent translation |
|---|---|---|---|---|---|
| MEM-01 | Semantic retrieval breadth drives the memory-creativity link | A meta-analysis of 525 correlations (79 studies, 12,846 participants) found an overall memory-creativity correlation of r=.19, driven mainly by semantic memory, especially verbal fluency. Working memory was tied more to convergent thinking, and working-memory capacity correlated only r=.08 with divergent thinking (28 studies, N=3,104). In one study, broad retrieval ability correlated r=.47 with divergent thinking. A preprint (N=45) found semantic details explained 36% of divergent-thinking variance (beta=0.51), and episodic detail added nothing once semantic detail was included (BF10=0.31). | meta-analysis | encode | Give retrieval breadth its own step before generation. (1) In /encode, a subagent runs a fluency sweep, listing as many relevant mechanisms, materials and phenomena as it can in categories taken from problem.md (web search optional), and writes them to retrieved.jsonl. (2) It retrieves semantic abstractions from memory/semantic/ first, plus a python/embedding concept expansion: neighbours of each key problem noun at several distances. (3) Before /forage, each subagent gets 5-10 snippets chosen by MMR to maximise distance from each other. Past-run narratives are never given as idea content. Episodic logs inform only control decisions such as which budget or seed types worked. Holding all constraints in context, the working-memory analogue, belongs to /evaluate's convergent checking. Harness: test whether retrieved-snippet diversity predicts idea diversity. |
| MEM-02 | Cross-episode compression into a reusable schema library | Library learning alternates between solving tasks and refactoring shared sub-programs into a growing library, which makes later search cheaper. DreamCoder rediscovered concepts such as Newton's and Coulomb's laws this way, and LILO extended the loop with LLM-guided synthesis plus symbolic compression. In structure-mapping theory, aligning two cases makes their shared higher-order relations salient and available for transfer. iOtA proposes that replaying overlapping memories together strengthens shared elements while details fade. Darden describes scientists generating hypotheses by instantiating abstract schema types from a stored repertoire. | replicated | consolidate | /consolidate writes semantic memory by comparing episodes, not by summarising single ones. A periodic pass (for example every 10 runs) runs a python job that embeds memory/episodic/ logs and clusters close ones (at least 2-3 successful runs per cluster). For each cluster, a subagent aligns the cases as a relation table. It writes the shared relational schema to memory/semantic/schemas/ as a parameterized abstraction with content slots and no surface detail, then removes duplicates. A single episode is never promoted. /encode retrieves schemas using a structural description of the new problem. A 'schema' /forage mode fills the top-k schemas' slots with problem elements and logs {mode: schema, schema_id} in ideas.jsonl. Harness: track solve rate as the library grows and which schemas pay off. Always run alongside a memory-blind flexible forage agent. |
| MEM-03 | Insight-weighted consolidation | High-insight solutions were about twice as likely to be remembered 5 days later as low-insight ones (OR=2.10) and 7.78x more likely than unsolved items. The advantage was carried by representational change and anterior hippocampus activity, not by the amygdala (Becker 2025, N=31). Separately, unrelated facts shown just after an Aha solution, before the answer was typed, were remembered better (Salvi 2024, N=291), which suggests a temporally extended encoding state. | replicated | consolidate | /consolidate weights what it writes by measured representational change (embedding distance between the initial and final problem framing) and by surprise, not by evaluator enthusiasm. Verified high-change solutions get a full semantic abstraction entry; low-change ones get only an episodic log. When /insight-check confirms a true insight, the surrounding context is also stored, tagged with the insight id: the seed, the preceding 3 trajectory steps and the sibling ideas in that cluster. /encode can then retrieve the conditions that produced it. Harness: test whether change-weighted memories are retrieved and useful more often on later problems. |
| MEM-04 | Flexible, interconnected semantic network | Across two studies, high crystallised-intelligence groups had more flexible semantic networks (more clustered and interconnected, less rigidly structured), proposed as their link to creativity. Low-creative individuals' free-association networks were more rigid, spread out and fragmented. | replicated | consolidate | /consolidate does more than append entries. Each new semantic abstraction is embedded and linked to its nearest k entries across domains in memory/semantic/links.jsonl, with the shared relation written down. A python script tracks graph metrics over time (clustering, average path length, number of components). Rising fragmentation triggers a cross-linking pass. /encode retrieval follows the links one hop out. |
| MEM-05 | Retrain the intuitive first move instead of adding deliberation | Short training improved the intuitive stage itself: most trainees then solved problems correctly without deliberating (N=147). The effects lasted two months across six studies and held in Himba participants. Knowledge automatization drives sound intuitions. | replicated | consolidate | For each solved problem, /consolidate writes a compact 'correct first move' abstraction plus the trap it avoided into memory/semantic/. /encode retrieves the top matches by embedding and places them before any generation, so every subagent's fast first pass starts from the corrected framing rather than relying on later evaluation to catch the error. Harness: track first-answer accuracy across successive runs. |
| MEM-06 | Retro-cue re-evaluation of dormant and rejected ideas | The timing of ignition is flexible. A retro-cue given up to 900 ms after a stimulus can still produce conscious access, and items outside the focus survive through weak local firing or activity-silent storage. Humans also replay sub-optimal transitions more often than optimal ones. A model computing replay gain from a forgetful subjective model, fitted to MEG data (n=21), found replay raised the probability of an optimal choice by 3.36%. | replicated | restructure | Unselected and rejected ideas stay in ideas.jsonl as a dormant buffer instead of being discarded. After /restructure rewrites problem.md, a fresh /evaluate subagent re-scores every never-admitted idea, plus a sample of previously rejected ones, against the new framing, because they were judged under the old representation. Ideas that now pass the threshold are admitted to workspace.md. This happens in the evaluator, not the generator, so P8 (the fresh generator never sees failed ideas) still holds. Harness: count how often final solutions come from retro-cued or promoted ideas. |
| MEM-07 | Prioritized replay: need times gain, with weak items favoured | Normative theory: memories are accessed in order of utility, gain (the policy improvement from re-evaluating) times need (expected future relevance). This reproduces forward and reverse replay, and MEG replay in humans spread value to non-local states. fMRI showed that objects remembered less well were replayed more during awake rest. Rest replay predicted later improvement only in participants who slept during the interval. | single-study | encode | At the start of /encode and during /incubate, rank memory/episodic/ entries by need times gain. Need is the embedding similarity of the episode's problem to the current one. Gain is a cheap subagent's judgment of whether the episode's lesson would change the current default schema or shortlist. Only the top 3 are loaded. /consolidate tags stored framings and partial ideas with a confidence level and writes low-confidence, half-developed ones to memory/semantic/weak_queue.jsonl. These get a gain bonus, and a fresh subagent reworks them before generation on related runs. Offline, /consolidate re-reads high-need episodes to update semantic entries. |
| MEM-08 | Accumulation through stored exemplars and demonstrations | Learning from creative exemplars improved later creation. Exemplar trials that predicted better creation showed lower hippocampal representational dimensionality and stronger hippocampal-vlPFC connectivity, independent of how well the exemplar was remembered. Chimpanzees (66 in two groups) failed a sequential puzzle box over three months, while 14 naive chimpanzees learned it after watching trained conspecifics. Accumulation through transmission, not invention, is the human difference. | single-study | consolidate | /consolidate stores each verified solved run twice: as a replayable demonstration in memory/episodic/ (solution steps, verification command, framing) and as a one- or two-sentence structural principle in memory/semantic/ with domain detail removed. /encode retrieves the principles by embedding similarity as exemplars for structurally similar problems, so later runs build on earlier solutions instead of re-inventing them. Harness: on held-out problems, compare full exemplar vs compressed principle vs none (the human data predict the compressed form wins), and compare solve rate across sequential runs with memory on and off. |
| MEM-09 | Compression-governed library growth: expand only when needed, merge and prune | People's named part concepts for about 2,000 procedurally generated objects follow an information-theoretic tradeoff: each object can be described concisely, while the lexicon stays small. AXIOM adds a model component only when no existing one explains new data. Every 500 frames it tests merges by Bayesian model reduction and keeps those that lower expected free energy (EFE). Ablating reduction dropped Gold from 190 to 45 and Hunt from 206 to 48. | single-study | consolidate | Admission rule for memory/semantic/: a candidate becomes a new entry only if (a) no existing entry has embedding similarity above a threshold and a fresh subagent judges that none already explains it, and (b) rewriting past episodes with it shortens their total token length by more than its own length, measured by a python script in the /consolidate compression pass. Every N runs, a script proposes merges of close pairs. A subagent writes the merged abstraction, which replaces both only if harness retrieval tests do not degrade. Entries never retrieved after N runs are pruned. |
| MEM-10 | Named, documented abstractions get reused more | LILO's auto-documentation step gives compressed abstractions natural-language names and docstrings, which measurably improved their later reuse by the synthesizer. LILO solved more complex tasks and learned richer libraries than DreamCoder on string editing, scene reasoning and graphics. | single-study | consolidate | Every memory/semantic/ entry needs a short descriptive name, a one-paragraph docstring saying when it applies and what it transforms, and one usage example. /encode retrieval embeds the docstring, not the raw episode. A lint script in /consolidate rejects entries with no name or docstring. |
| MEM-11 | Keep competing versions, select by use, protect old knowledge | Intracranial recordings (N=11) showed that among several cortical traces of the same object, the one more strongly reactivated during about 30 minutes of rest was later retrieved. Reactivation was locked to hippocampal ripples, and hippocampal-DMN interactions preceded it (p=.016). In models, alternating hippocampus-driven NREM replay with neocortex-internal REM replay stopped new learning from overwriting existing knowledge, but no human study has manipulated the alternation. | single-study | consolidate | /consolidate never overwrites. It alternates two passes for 2 cycles: (a) integrate, which writes new abstractions from the run; (b) self-replay, which rereads existing semantic entries and checks that the new ones do not contradict or silently replace them. Conflicting versions are kept side by side, each with a usage counter that is incremented when /encode retrieves it and it contributes to an accepted idea. A periodic python pruning job keeps the most-used version and moves the others to memory/archive/. The harness re-runs earlier benchmark problems after memory updates to catch forgetting. |
| MEM-12 | Memory replay as raw material for spontaneous thought | Intracranial recordings (10 patients, up to 15 days) showed higher hippocampal sharp-wave ripple rates during periods of vivid, imaginable, task-decoupled self-generated thought. This supports spontaneous thought drawing on memory replay. | single-study | wander | Before a /wander run, a python helper randomly samples 2-3 entries from memory/episodic and memory/semantic, weighted toward low similarity to the current problem. They are injected as replay material that the walk must pass through at its jump points. Past runs then become a source of spontaneous content, not only a retrieval target for /encode. |
| MEM-13 | Exploration pays off through the evidence it gathers | In four learning-trap studies, children explored more than adults and learned the true structure better. Adults given child-like evidence learned like children, and children given adult-like evidence learned like adults, so the advantage was caused by the evidence exploration produced. | single-study | incubate | Exploratory agents (/wander, flexible /forage) write the raw facts they surface (observations, test results, retrieved examples) to runs/<id>/evidence.jsonl, kept separate from their conclusions. The fresh agent spawned by /incubate and the /evaluate pass get this evidence pool, but not the explorers' reasoning or ideas. Exploration then pays off through better data rather than through inherited framings. |
| MEM-14 | High-confidence errors drive durable memory updating | After high-confidence errors, information seeking protected updated memories from 24-hour decay. When initial curiosity was low, surprise after the error increased seeking and made the updating durable. | preprint | consolidate | /consolidate processes false insights from insight.log first. Each high-confidence idea that failed verification becomes an episodic entry holding the claim, the logged confidence, the failing test and the corrected understanding. It also gets a semantic 'trap' note that /encode retrieves by embedding on similar problems and adds to the fixated-cues list. |
| MEM-15 | ANTI: Purely syntactic matching when merging abstractions | DreamCoder's abstraction search is purely syntactic, so it misses shared structure hidden by superficial variation. babble uses e-graphs plus anti-unification, so that 2+1 and 1+3 can be refactored under one abstraction. | preprint | consolidate | When /consolidate merges or deduplicates memory entries (MEM-02, MEM-09), it never matches on wording or raw embedding similarity alone. A subagent first rewrites each candidate into a canonical relational form with roles and relations and no content. It then anti-unifies pairs: what is shared stays, and differences become slots. Entries merge only when their canonical forms coincide. |
| MEM-16 | Generative replay: early generalization gains, schema distortion | In simulations, hippocampal replay trains neocortical generative models that support semantic memory, imagination and episodic future thinking. The same process produces schema-based distortions such as boundary extension (Spens & Burgess 2024). In a ventral-stream and hippocampus model, generative replay that resembles imagining new category instances improved generalization, but only during early learning (Barry & Love 2022). | theory | consolidate | Assume /consolidate's abstractions will drift toward generic schemas. Keep raw episodic logs unchanged and link each semantic entry to its source files. Periodically, a fresh subagent compares each abstraction against its sources and flags claims the episodes do not support; flagged entries are corrected or deleted. When a new abstraction has few supporting episodes, a subagent generates 3-5 synthetic variant problems it ought to cover and tries applying it to each. Failures narrow or annotate the entry. Skip the synthetic step for mature abstractions with many supporting episodes. |
| MEM-17 | ANTI: Paper disruptiveness decline is contested | Across 45M papers and 3.9M patents, the CD index shows declining disruptiveness linked to narrowing use of prior knowledge. Critics attribute this to zero-reference entries, and the authors' rebuttal says it holds in the critics' own model. One analysis finds trends at noise level for 1995-2015. | contested | consolidate | Treat this as a risk for memory, not a proven law. As memory/semantic grows, /encode retrieval may narrow every run toward stored framings, schemas and demonstrations (MEM-02, MEM-08). Log which memory entries each run retrieves and have the harness track run diversity as memory grows. Cap injected stored framings per run (for example 2) and keep one forage agent memory-blind. |
| MEM-18 | ANTI: curiosity opens a general encoding window | In three task versions, unrelated facts shown near high-curiosity trivia answers were remembered worse than those near low-curiosity ones, contradicting earlier incidental-face benefits (Gruber 2014). Children's curiosity gains did not engage the hippocampus or accumbens. | contested | consolidate | Do not fold side observations into the memory entry of an exciting result. /consolidate stores each incidental finding as a separate semantic or episodic file with its own embedding, so retrieving the headline result cannot crowd it out. This also argues against leaning on the post-insight context window in MEM-03. It is mainly a design caution, because LLM file memory has no encoding interference. |

### Sources and caveats

- **MEM-01**. Sources: Gerver, Griffin, Dennis & Beaty 2023, https://link.springer.com/10.3758/s13423-023-02303-4; WMC meta-analysis 2023, https://pubmed.ncbi.nlm.nih.gov/36662145/; Miroshnik et al. 2023, https://www.sciencedirect.com/science/article/abs/pii/S016028962300020X; Thakral et al. 2026 (preprint), https://www.biorxiv.org/content/10.64898/2026.02.08.704672v1.full. Caveats: The effect is small and correlational (r=.19). The r=.47 comes from one study, and the semantic-over-episodic result from one preprint (N=45, one divergent-thinking measure). Human fluency reflects capacity, while LLM retrieval breadth depends on the prompt; external retrieval may anchor rather than broaden. LLMs already hold a huge semantic memory, so the lever is what gets retrieved into context. Merged from: Semantic memory drives the memory-creativity link [memory_semantic_networks_and_combination]; Retrieval fluency beats working memory for ideation [modulators_and_practical_levers]; Semantic scaffold outweighs episodic detail [brain_networks_of_creativity].
- **MEM-02**. Sources: Ellis et al. 2020, https://arxiv.org/abs/2006.08381; Grand et al. 2024, https://arxiv.org/abs/2310.19791; Gentner & Forbus 2025, https://groups.psych.northwestern.edu/gentner/papers/GentnerForbus-2025-SME.pdf; Lewis, Knoblich & Poe 2018, https://pmc.ncbi.nlm.nih.gov/articles/PMC7543772/. Caveats: Replicated evidence comes from program-synthesis systems, not humans, and solve rates were not retrieved. Structure mapping, iOtA and Darden are theory or case studies, with no 2023-2026 creativity test found. DreamCoder's matching is syntactic and brittle (see MEM-15), and LLM case alignment is brittle too. A schema library can increase fixation on known mechanism types (see MEM-17). Schema instantiation is partly a generation mechanism, so it is mis-tagged here. Merged from: Compress solutions into a reusable abstraction library [computational_models_of_thinking]; Comparing analogs abstracts reusable schemas [memory_semantic_networks_and_combination]; Overlap-based gist extraction across episodes [sleep_dreams_and_replay]; Schema instantiation from a mechanism library [philosophy_of_thought_and_creativity].
- **MEM-03**. Sources: Becker 2025, https://www.nature.com/articles/s41467-025-59355-4; Danek & Wiley 2020, https://www.psycharchives.org/handle/20.500.12034/2732; Salvi 2024, https://par.nsf.gov/servlets/purl/10557988; CNS 2026 abstract, https://www.cogneurosociety.org/poster/?id=6811. Caveats: N=31 on Mooney images, and about 18.7% of 'correct' responses may be misclassified. Kizilirmak 2019 found hippocampus-independent learning. Salvi 2024 was read without full statistics, and the general encoding-window idea is undermined by the curiosity non-replication (MEM-18). LLM memory is file retrieval, not encoding strength, so context tagging is a heuristic only. Merged from: Insight strength predicts lasting memory [insight_and_aha_moments]; Post-insight window boosts incidental encoding [insight_and_aha_moments].
- **MEM-04**. Sources: Li, Beaty, Luchini, Hu & Kenett 2024, https://pure.psu.edu/en/publications/the-role-of-semantic-memory-networks-in-crystallized-intelligence/; Kenett, Anaki & Faust 2014, https://public-pages-files-2025.frontiersin.org/journals/human-neuroscience/articles/10.3389/fnhum.2014.00407/text. Caveats: Group-level, correlational network estimates. Hills & Kenett argue the apparent structure may come from retrieval dynamics. A file-based link graph is only a loose analogue of human semantic networks. Merged from: Flexible, interconnected semantic memory supports creativity [thought_dynamics_and_mind_wandering].
- **MEM-05**. Sources: Franiatte et al. 2024, https://pmc.ncbi.nlm.nih.gov/articles/PMC11025568/; Franiatte et al. 2025, https://doi.org/10.1016/j.actpsy.2025.105131; Boissin et al. 2024, https://doi.org/10.1016/j.cognition.2023.105681. Caveats: Mostly one lab, on reasoning-bias tasks with known answers, not open-ended ideation. In-context retrieval is not weight change, so the benefit depends on retrieving the right abstraction. It complements the trap notes in MEM-14. Merged from: Debias by retraining intuitions, not adding deliberation [reasoning_metacognition_and_working_memory].
- **MEM-06**. Sources: Mashour et al. 2020, https://pmc.ncbi.nlm.nih.gov/articles/PMC8770991/; Kouider et al. 2013, https://doi.org/10.1126/science.1232509; Antonov et al. 2022, https://www.biorxiv.org/content/10.1101/2021.04.27.441454v1.full-text; Eldar et al. 2020, https://elifesciences.org/articles/56911. Caveats: Only the retro-cue finding is replicated, on a timescale of hundreds of milliseconds and summarized through a review. The replay-of-rejected-options result is one small study, and the model predicted replay harmed two subjects. Workspace files do not forget, so the decay driver does not transfer, only the logic of re-evaluating after a change. Arguably belongs to evaluation or control. Merged from: Retro-cue: late access for unselected items [consciousness_and_global_workspace]; Replaying rejected options improves later choices [computational_models_of_thinking].
- **MEM-07**. Sources: Schapiro 2018, https://ideas.repec.org/a/nat/natcom/v9y2018i1d10.1038_s41467-018-06213-1.html; Mattar & Daw 2018, https://pmc.ncbi.nlm.nih.gov/articles/PMC6203620; Liu et al. 2021, https://doi.org/10.1126/science.abf1357. Caveats: Gain times need is a normative theory with partial human support; humans also over-replay sub-optimal transitions. The weak-item finding is one foundational fMRI study with no effect sizes in the notes, and its benefit depended on sleep, which has no analogue in an LLM pipeline. Merged from: Replay prioritized by gain times need [computational_models_of_thinking]; Offline replay prioritizes weakly learned items [sleep_dreams_and_replay].
- **MEM-08**. Sources: Zhang et al. 2025, https://www.nature.com/articles/s41467-025-67157-x; van Leeuwen et al. 2024, https://europepmc.org/articles/PMC11132989; Reader & Laland 2002, https://europepmc.org/articles/PMC123666. Caveats: The exemplar sample size was not in the fetched abstract, and low neural dimensionality is only loosely analogous to text summarization. The chimpanzee study used one puzzle type, and transmission is arguably a social mechanism, so it is mis-tagged here. Retrieved demonstrations may anchor and fixate later runs (see MEM-17). Merged from: Exemplar learning through compressed abstraction [brain_networks_of_creativity]; Social transmission compounds isolated innovation [development_language_and_culture].
- **MEM-09**. Sources: Wong et al. 2022, https://arxiv.org/abs/2205.05666; Heins et al. 2025, https://arxiv.org/html/2505.24784v1; Smith et al. 2020, https://frontiersin.org/journals/computational-neuroscience/articles/10.3389/fncom.2020.00041/full. Caveats: Wong et al. is a conference paper on one domain of visual objects. AXIOM is a company-affiliated arXiv preprint on simplified games with hand-engineered priors, and reduction hurt the Cross game. Token-count description length is a crude proxy for MDL, and text memories have no direct model-evidence metric. Merged from: Library size traded against description length [computational_models_of_thinking]; Expand-then-reduce structure learning [predictive_processing_and_active_inference].
- **MEM-10**. Sources: Grand et al. 2024, https://arxiv.org/abs/2310.19791. Caveats: One ICLR paper on program synthesis, with no effect size retrieved. The human analogue (having a word for an idea helps reuse) is the notes' own inference and was not tested. Merged from: Named, documented abstractions get reused more [computational_models_of_thinking].
- **MEM-11**. Sources: Duan 2025, https://faculty.wcas.northwestern.edu/~paller/Progress%20in%20Neurobiology%202025.pdf; Singh, Norman & Schapiro 2022, https://neurosciencenews.com/memory-sleep-hippocampus-neocortex-21719; Lewis, Knoblich & Poe 2018, https://pmc.ncbi.nlm.nih.gov/articles/PMC7543772/. Caveats: The trace-selection result comes from 11 epilepsy patients, is correlational, and used object-location memory rather than ideas. The NREM-REM alternation is computational only; Schapiro says 'we still need to test this'. The usage-counter and two-pass analogues are loose. Merged from: Rest reactivation selects among competing traces [sleep_dreams_and_replay]; NREM-REM alternation prevents knowledge overwriting [sleep_dreams_and_replay].
- **MEM-12**. Sources: Iwata et al. 2024, https://www.ncbi.nlm.nih.gov/pmc/articles/PMC11111804/; Varma & Yu 2023, https://resolve.cambridge.org/core/journals/behavioral-and-brain-sciences/article/spontaneous-neural-replay-account-for-involuntary-autobiographical-memories-and-deja-vu-experiences/D2547BFF45DF24D8104447F6BFDF99F8. Caveats: N=10 epilepsy patients, correlational, read at abstract level only. Ripple rate magnitudes and timing are unknown. 'Replay' in an agent is just file sampling, an analogy rather than a mechanism. It is closer to generation than to memory, so it is partly mis-tagged. Merged from: Memory replay feeds self-generated thought [thought_dynamics_and_mind_wandering].
- **MEM-13**. Sources: Liquin & Gopnik 2022, https://doi.org/10.1016/j.cognition.2021.104940. Caveats: One paper (four studies) from one lab, on approach-avoid tasks. Exploration costs reward in the short run, and transfer to an LLM reading evidence files is untested. It is mainly a control (exploration) finding, mis-tagged as memory, though the agent mechanism is an evidence store. Merged from: Exploration helps through the evidence it gathers [development_language_and_culture].
- **MEM-14**. Sources: Poh 2026, https://doi.org/10.31234/osf.io/yx6ek_v1. Caveats: Preprint with no sample size given. In the LLM version, confidence is logged rather than felt and surprise is not modelled. It pairs with the correct-first-move entries in MEM-05. Merged from: High-confidence errors drive durable memory updating [emotion_body_and_curiosity].
- **MEM-15**. Sources: Cao et al. 2022, https://arxiv.org/pdf/2212.04596. Caveats: Program-synthesis evidence only, cited from arXiv. Having an LLM canonicalize prose can itself introduce errors. Merged from: ANTI: Purely syntactic matching when merging abstractions [computational_models_of_thinking].
- **MEM-16**. Sources: Spens & Burgess 2024, https://doi.org/10.1038/s41562-023-01799-z; Barry & Love 2022, https://discovery.ucl.ac.uk/10145147/1/bhac054.pdf. Caveats: Computational models only, not human experiments. Whether LLM-written summaries distort the same way is plausible but untested. Synthetic problems generated by the same model may share its blind spots. Merged from: Generative consolidation introduces schema distortions [predictive_processing_and_active_inference]; Imagined instances aid early category generalization [sleep_dreams_and_replay].
- **MEM-17**. Sources: Park, Leahey & Funk 2023, https://doi.org/10.1038/s41586-022-05543-x; Holst et al. 2024, https://arxiv.org/abs/2402.14583; Park et al. 2025, https://arxiv.org/abs/2503.00184. Caveats: Active dispute, though about 100 studies report the same direction. Even if real at population scale, the narrowing mechanism is only an analogy for an agent's memory store. It is arguably a social or measurement finding. Merged from: ANTI: Paper disruptiveness decline is contested [development_language_and_culture].
- **MEM-18**. Sources: Keller 2024, https://doi.org/10.1038/s41539-024-00234-w; Gruber 2014, https://pmc.ncbi.nlm.nih.gov/articles/PMC4252494/; Ziv 2026, https://doi.org/10.1016/j.dcn.2026.101687. Caveats: A human encoding effect; the LLM analogue (retrieval crowding) is weak. Sample sizes were not available, and the result conflicts with the Gruber 2014 incidental benefit. It also bears on the state function (curiosity as a modulator). Merged from: ANTI: curiosity opens a general encoding window [emotion_body_and_curiosity].
