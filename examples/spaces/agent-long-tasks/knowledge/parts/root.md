# Harness fixes for long tasks

Find which changes to the harness, not the model, raise the pass rate of the coding agent on long tasks (40 or more tool calls), and by how much. Long tasks pass 31 percent of the time against 78 percent for short ones, and the same task often passes on one run and fails on the next.
